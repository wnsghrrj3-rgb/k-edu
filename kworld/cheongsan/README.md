# 시간 탐험대 · 「청산리 — 엿새」

정본 설계: `docs/kedu-world/시간탐험대_청산리_엿새_설계_v1.md`(뼈대) · `…_v2_상세.md`(기준). 들어간 것: 차례 1(큰 지형 + 새 조작 셋 + 장 0·1, 11-23) · 차례 2(장 4 어랑촌) · 차례 3(장 3 천수평 + 값 넘기기) · 차례 4(장 5 쫓기는 길 지도 판) — 11-23 준호 「계속 진행」. 아직 없는 장은 `main.js` CHAPTERS 에 null — 건너뛰고 끝 화면에 「만드는 중」.

## 파일(설계 ⑨ 틀)
- `main.js` 장 엔진: 띠 넷(부대·포위망·탄약·배고픔) · 꼬리표(`S.tags`) · 장 넘기기(밤이 지나면 배고픔 +22·포위망 +12) · 저장(`kworld_cheongsan_save_v1`, 장 끝마다 — 게스트·방문자는 `kedu_scope.js` 규칙대로 기기에 안 남음) · 끝 화면 · 시점 · 작은 지도(적 다섯 갈래: 살핀 갈래만 붉은 화살) · 새 조작(C 엎드리기 · Space 꾹 살피기 · F 신호) · 들킴 눈금 · 고르기 판(숫자 1~4).
- `map.js` 높이 함수 하나(H)로 땅 그물·발 디딤·시야·작은 지도. 골짜기 = 꺾은선을 깎은 홈(백운평~청산리~갑산촌~천수평~어랑촌, 완루구, 고동하). 숲(가까운 곳 블렌더 나무 · 먼 곳 값싼 나무), 먼 산 세 겹.
- `enemy.js` 인스턴스 병사 줄(길 위 머리 s · 멈칫 halt · 물러감) · 쓰러지면서 사라짐 · 총구 불빛·연기·산포 고리 · 연기 기둥.
- `people.js` 이름 있는 사람(kit 사람 + 털모자·총·등짐·망원경) · 말풍선.
- `ch0.js` 앞날: 명령 → 망바위 연기 넷(하나는 옆 바위에서만) → 알리기(회의) → 비탈 여섯 자리 살피기(○○○ 둘·○○ 둘·○ 둘) → 이범석에게 두 자리 → 밤. 넘기는 값 `grade A/B/C` · `smokeAll` · `baggage` · `calm`.
- `ch1.js` 백운평: 흔적 셋(놀이 장치) → 신호 자리 엎드리기 → 숨죽이기(기침·까마귀·멈칫) → 꼬리가 표지 바위를 지나면 F → 싸움(등급별 −2/−6/−12) → 본대·산포(망바위에서 살피고 F 면 「거두어라」 전에 빠짐 · 한 번 더 칠까) → 고갯마루.
- `ch3.js` 천수평(새벽, 같은 날 어랑촌으로 곧바로): 갑산촌 문 연 집 셋(할머니 · 나무꾼 = 보초 자리 + 1분 · 겁먹은 집) · 밥 얻기 · 망원경으로 길 넷·보초 넷(붉은 시야 고리) · 바람 위쪽(서쪽) 28 m 안이면 말이 운다(들킴 +30) · 조 넷을 길목에 · 길목 고리에서 F · 안 막은 길 = 놓친 기병(→ 어랑촌 40초씩 더) · 탄약 +30·쌀·말 · 흔적 지우기. 블렌더에 `cs_horse`·`cs_tent_jp` 더함.
- `ch5.js` + `strat.js` 쫓기는 길: 종이 지도 판(마디 열 · 길 셋 — 큰길 포위망 +5·배고픔 +4 / 능선 +2·+10·적 두 갈래 살핌 / 물길 +1·+5·부대 −1), 배고픔 80 넘으면 마디마다 부대 −3, 가운데에 23일 밤(내일 길 권하기). 사이 장면 넷 가운데 판마다 셋(`?seed`): 맹개골 뒤를 맡을 조(바위 셋에 놓으면 잃는 것 반) · 만기구 거짓 불(두 마디 포위망 −4, 수색조 엎드려 넘기기) · 쉬구 마을(밥·소식·소년 지름길·흔적) · 천보산 아래 맞닥뜨림(엎드려 넘김/싸움). 사이 장면은 물줄기 북쪽 둑에서.
- `ch4.js` 어랑촌: 능선 셋 밀림 띠 · 예비대(하나, 걸어서 옮김) · 탄약 나르기(능선마다 눈금, 상자 = 탄약 띠 −5) · 기관총 자리(44초 넘게 두면 산포가 노림, 8초 붉은 고리) · 한낮 주먹밥(능선마다 −15, 다 나누면 배고픔 −35) · 홍범도 전령 고르기(내가 뜀 = 60% / 기다림 = 80%, 전갈닿음 0 이면 안 옴) · 다친 순길 부축 · 마을에 알림. 길잡이 카드가 가장 급한 일을 가리킨다(기관총 위험 > 주먹밥·탄약 내려놓기 > 오래 둔 기관총 > 전령 > 예비대 > 탄약 > 주먹밥 받기). 지형: `map.js` eorang() — 지휘소 우묵한 곳 + 능선 셋.
- 그림: `kworld/tools/blender/make_cheongsan.py` → `kworld/scene/assets/cheongsan.glb`(38개 — 자작·잎갈·전나무, 바위벽, 천막, 모닥불, 귀틀집, 털모자·군모·총·등짐·망원경, 병사 몸 다섯(인스턴스), 까마귀, 산포, 기관총). 깃발·모자에 표지 없음.

## 가벼움
숲은 터(백운평·어랑촌·고동하)와 먼 칸마다 따로 그려 화면 밖은 건너뛴다(인스턴스 경계 구를 다시 셈). `?lite=1` 또는 코어 4개 이하면 나무 수를 줄인다.
