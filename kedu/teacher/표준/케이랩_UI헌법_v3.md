# 케이랩 2.0 — UI 헌법 v3 (2026-07-11)

케이뮤지엄 "밤의 박물관"의 절제 문법을 밝은 교실 톤으로 옮긴 표준.
뮤지엄 = 밤·황동·신비 / 케이랩 = 낮·정밀·조작. 가족이되 같은 옷은 아니다.

## 1장 — 다섯 원칙

1. **액센트는 과목당 1색.** 화면의 모든 강조는 `--kl-accent` 하나에서 나온다.
   수학 #3D74D9 · 국어 #E8791E · 영어 #D94F82 · 사회 #7C5CE0 · 과학 #17A589
   (허브 klab.html이 mount 시 주입 — 도구는 색을 하드코딩하지 않는다)
2. **크롬은 중립.** 탭·배너·독·필의 바탕은 회색 계열(--kl-ink/--kl-mut/--kl-line/--kl-soft).
   색으로 소리치는 건 무대 위 교구와 액센트뿐이다.
3. **조작 3단계 위계.**
   ① 무대 위 직접 조작 (교구 자체를 만진다 — 버튼이 아니라)
   ② 하단 독 `ui.dock()` 한 곳 — 핵심 조작 최대 3~4개, `pri` 1개
   ③ 부가 기능(학년칸 등)은 우상단 소형 필로 물러난다
4. **테두리 1.5px, 굵기 700 이하, 라디우스 12~14px.** 3px 테두리·800 굵기 금지.
5. **모드는 세그먼트 하나.** 자유탐구/미션/퀴즈는 `.kl-seg` 세그먼트 컨트롤 —
   버튼 세 개가 아니라 스위치 하나로 읽혀야 한다.

## 2장 — 화면 뼈대 (위→아래)

```
[우상단: 학년칸 필 🌱🌿🌳]          ← 부가 기능, 작게
[중앙: 모드 세그먼트]                ← 스위치 하나
[미션/퀴즈 스트립 .kl-bar]           ← 좌측 액센트 굵은선 + 칩 + 본문
[무대 .kl-stage-host]               ← 화면의 주인공, 직접 조작
[하단 독 .kl-dock]                  ← 조작 버튼의 유일한 자리
[선택지 .kl-choices / 상태줄]
```

## 3장 — 공통 헬퍼 (engine/klab.js v3)

- `ui.ensureCss()` — v3 스타일시트 1회 주입 (각 헬퍼가 자동 호출)
- `ui.dock(items)` — 하단 조작 독. `{act,label,kind:'pri'|'ghost',cls}`
  data-act 유지 → 기존 바인딩 그대로 동작
- `ui.modeTabs / missionBar / quizBar / doneBar / choices / toast / gradeBands`
  — API 동일, 비주얼만 v3. **도구 코드 수정 없이 전 도구 적용됨**

## 4장 — 도구 이행 체크리스트 (도구당 5분)

- [ ] 자체 버튼 스타일 문자열(`var btn=...`) 삭제 → `ui.dock()`으로 교체
- [ ] 독을 무대 **아래**에 배치 (`stage + ctrl + foot` 순서)
- [ ] 도구 내 하드코딩 색을 `var(--kl-accent)`로 교체
- [ ] hover/active 오버라이드가 v3 클래스와 충돌하지 않는지 확인
- 골든 샘플: `tools/tenframe.js` (2026-07-11 이행 완료)

## 5장 — 하지 않는 것

- 화면 상단에 조작 버튼 깔기 (조작은 무대 아니면 독)
- 한 화면에 액센트 2색 이상
- 배너 안에 버튼 넣기 (만약에 엔진 등 기존 예외는 차기 이행 때 정리)
- 이모지를 위계 대신 쓰기 (라벨 앞 장식 1개까지만)
