# 케이랩 깊이 헌법 v1 (2026-07-11)

"1+1이면 1+1만 조작되는" 닫힌 도구를 → 규칙만 주고 무엇을 만들지는 아이가 정하는
**열린 교구**로. UI 헌법 v3(모양)과 짝을 이루는 내용의 헌법.

## 네 가지 장치

### ① 상태의 자유
도구 밑에 진짜 모델이 돈다. 아이가 어떤 상태를 만들든 도구는 정직하게 반응한다.
상태 변경은 단일 진입 함수(setNum 등)로 모아 어디서 바꿔도 표상·판정이 따라온다.

### ② 표상 동시 연결
조작 → 기호가 **실시간 동시에** 변한다. 점을 가르면 수식(5+2=7)과 수직선 두 호가
같은 순간 바뀐다. 무대 아래 `.tf-rep`류 표상 스트립 — 퀴즈 모드에서는 숨김(답 노출).

### ③ 발견 모으기 (정답 1개 미션의 반대)
"8을 5와 3으로 갈라라" → "**8을 가르는 방법을 몇 가지나 찾을 수 있어?**"
- 도구는 지시하지 않고 아이의 발견을 **인정**한다 (유효 상태 자동 감지 → 카드 수집)
- 컬렉션 UI: 찾은 짝은 액센트 칩, 남은 짝은 `?+?` 유령 칩 — 남은 개수가 탐구 동기
- 조작 과정의 중간 상태도 발견으로 인정된다 (연속 탭 = 연속 발견, 이게 맞다)
- 학년칸: 저 = 수 진행(5→10) 고정·짝은 1..t-1 / 중·고 = 수를 아이가 고름·0 포함

### ④ 아이가 출제자
자기가 고른 상태를 문제 링크로 만들어 친구에게 보낸다.
허브가 `KLab.share(cfg, btn)` 제공 → `?tool=X&cfg={...}` 딥링크 복사.
출제가 가장 높은 사고 수준이다.

## 도구 이식 가이드 (골든 샘플: tenframe v5)

새 모드 `discover`를 modeTabs extraLabels(`{discover:'💡 발견'}`)로 추가하고,
도구별로 "발견의 단위"를 정의한다:

| 도구 | 발견의 단위 | 컬렉션 완성 |
|---|---|---|
| 십 배열판 | t의 가르기 (b,o) | t-1 또는 t 가지 |
| 곱셈 배열판 | n을 만드는 직사각형 (r×c) | n의 약수 짝 전부 |
| 나눗셈 모형 | n을 나머지 없이 담는 묶음 크기 | n의 약수 전부 |
| 분수 | 같은 크기의 다른 표현 | 동치분수 k가지 |
| 넓이 격자 | 넓이 n이 되는 서로 다른 모양 | k가지 (합동 제외) |
| 규칙·패턴 | 같은 다음 항을 만드는 다른 규칙 | 열린 수집 |

판정 함수는 순수 함수로: `checkDiscover(상태) → key | null`. key 중복이면 무시.
