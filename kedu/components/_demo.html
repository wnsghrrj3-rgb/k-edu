K-edu Components — Demo

컴포넌트표준 v1 시각·동작 검증. 좌(인라인 원본) vs 우(<kedu-*> 컴포넌트). 시각 동일하면 통과.

Case 1 — ten-frame default count=6 size=md

기본 표시 모드. 왼쪽부터 6칸이 채워진다.

인라인 원본

<kedu-ten-frame>

Case 2 — ten-frame size sm / md / lg / xl

size attribute 변화 → 크기 변경.

인라인 원본 (sm·md·lg)

<kedu-ten-frame> (sm·md·lg·xl)

Case 3 — ten-frame interactive (target=8)

빈 칸 클릭 → 왼쪽부터 채워짐. 8칸 채우면 complete 이벤트, 9칸 가면 overflow.

인라인 원본 (수동)

count: 0 (목표 8)

<kedu-ten-frame mode="interactive" target="8">

count: 0 (목표 8)

Case 4 — linking-cube stairs range=1,9

1부터 9까지 계단형 큐브 + 숫자 라벨.

인라인 원본

<kedu-linking-cube>

Case 5 — linking-cube stairs range=0,5 show-zero highlight=3

0 표시 + 3 강조. 학생 라이브에 동일 자리는 없지만 표준 사양 검증용.

인라인 원본 (없음)

학생 라이브에 동일 자리 없음. show-zero·highlight props 단독 검증.

<kedu-linking-cube>

Case 6 — linking-cube single count=5

단독 배치, 배경 박스 있음.

인라인 원본

<kedu-linking-cube>

Case 7 — CSS 변수 override

--kedu-lc-cube-color 등 변경 → 큐브 색 따라옴.

기본 색

--kedu-lc-cube-color = #FFAB91
