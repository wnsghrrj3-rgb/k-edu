# 두 문의 3D 오브젝트

이 폴더에 아래 두 파일을 두면 허브 첫 화면의 두 문에 **자동으로** 얹힌다.
파일이 없으면 라인 심볼이 그대로 뜬다 — 화면은 어느 쪽이든 정상 동작한다(§0-9).

```
teacher.png   선생님 문 (파란 색면 위)
student.png   학생 문  (초록 색면 위)
```

## 규격

- **배경 투명 PNG** (색면은 카드가 이미 깔고 있다)
- 짧은 변 기준 **600px 이상**, 정사각에 가까운 비율 권장
- 화면에는 최대 130px(모바일 96px)로 줄어든다 — 잔글씨·가는 선은 뭉갠다
- **가벼워야 한다.** 한 장 150KB 이하 권장(§0-9 3초 화면). 무거우면 첫 화면이 늦는다

## 무엇을 그릴까

시안 기준:
- **teacher** — 칠판 · 책 · 연필꽂이 (파란 계열 클레이 3D)
- **student** — 가방 · 책 · 로켓 (초록 계열 클레이 3D)

두 장의 **재질·광원·시점이 같아야 한다.** 따로 뽑으면 한쪽만 붕 뜬다.
한 번에 두 오브젝트를 같은 프롬프트로 뽑고 잘라 쓰는 편이 안전하다.

## 늘릴 때

문이 늘어나면 파일명만 맞추면 된다(`dressDoors()`가 `#door-{역할} .door-art`를 찾는다).
