무대 위 컴포넌트를 보고 피드백 칸에 적는다 (여백·비율·계층·컬러·타이포). 베프에게 피드백 복사를 눌러 베프 세션에 붙여넣으면 끝. 만족하면 상태 배지를 눌러 LOCKED로.

베프 토큰으로만 반영한다

피드백을 받아 이 파일의 해당 컴포넌트만 수정하고 버전을 올린다. LOCKED는 절대 건드리지 않는다. 규약은 맨 아래 참조.

GPT 아트디렉터 + 이미지

GPT 아트디렉터 복사로 스크린샷 감평 프롬프트를 받아 붙인다. 이미지 에셋이 필요하면 기존 /board 파이프라인으로 뽑아서 컴포넌트에 꽂는다.

토큰 — v12 하우스 스타일

모든 컴포넌트는 이 변수만 사용한다. 위 학년군 토글을 누르면 아래 쇼케이스 전체가 해당 팔레트로 재도색된다 — 토큰 규율이 지켜지고 있다는 증거.

작업 규약 — 베프 세션용

  1. 새 컴포넌트는 쇼케이스 맨 아래에 <section class="comp"> 블록을 복제해 추가한다. data-id는 유일해야 한다 (예: kmaker-card, kedu-nav).
  2. 스타일은 반드시 [data-id="…"] .stage 스코프 안에, 색·간격·서체·라운드는 --k-* 토큰만 사용한다. hex 직접 입력 금지 — 학년군 토글이 어긋나면 토큰 위반이 있다는 뜻.
  3. 피드백 반영 시 data-version과 헤더의 v0.x를 함께 올린다.
  4. LOCKED 컴포넌트는 마크업·스타일 모두 수정 금지. 변경이 필요하면 준호가 잠금 해제를 먼저 선언한다.
  5. LOCKED 확정 시 이 파일을 핸드오프 레포에 커밋한다: design/playground.html + STATUS에 [LOCKED] 컴포넌트ID vX.X 기록. 이 파일이 단일 진실 원장이다.
  6. 이미지 에셋이 필요한 컴포넌트는 /board에서 생산한다 (하우스 스타일 프리앰블 필수). 완성 이미지의 파일명은 컴포넌트ID_에셋명.png.
