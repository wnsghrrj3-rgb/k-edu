# K-MAKER Release Strategy

## 단계 정의 (진입·졸업 조건 명시)

| 단계 | 대상 | 진입 조건 | 졸업 조건 |
|---|---|---|---|
| **Alpha** | 준호+금성초 동료 5인 | Phase A 완료(영속화·LLM·PDF 한글) | 5인 중 3인 2주차 자발 재사용, 저장 실패 0 |
| **Closed Beta** | 교사 30인(수기 초대) | Alpha 졸업 | 주간 Export 인당 ≥2, P0 0건 2주 연속 |
| **Open Beta** | 공개(무료) | Closed 졸업+비용 상한 검증 | 리텐션·비용 데이터로 가격 확정 |
| **V1** | 요금제 가동 | 결제 실동작+지표 대시보드 | — |
| **V1.1** | 협업·모바일 | V1 안정 4주 | Realtime 협업 실사용 |
| **V2** | 마켓·API·외부 플러그인 | Enterprise/크리에이터 수요 실신호 | — |

## 릴리즈 규율

- **매 배포 전제**: 전 회귀 스위트 그린(1,700+) → 실브라우저 캡처 검수 → 캐시버스터 갱신 → 정직 보고 갱신. 하나라도 생략한 배포는 배포가 아니라 사고다.
- **롤백**: 정적 배포 특성상 직전 커밋 재배포가 롤백. DB 마이그레이션은 forward-only + 백업 스냅샷 선행(MK_ADMIN 백업 구조 이식).
- **버저닝**: 제품 semver + 캐시버스터(v=YYYYMMDD) 병행. API는 v1 deprecated 선례대로 Sunset 헤더 규약 유지.
- **기능 플래그**: 화면 숨김은 플래그로 — 코드 삭제 금지(Bible §0). Beta 기능은 조직/사용자 플래그로 선노출.

## 채널·메시지

- Alpha~Closed: 커뮤니티 수기 초대만. 광고 지출 0. 메시지는 "수업 자료를 분 단위로" 하나로 고정 — 기능 나열 금지.
- Open Beta: keduclass.com 통합 노출(KLab 사용 교사 유입 동선). Education 무상은 첫 화면에 명시.
- 가격 발표는 Open Beta 데이터 이후 — 선발표 금지.

## 실패 프로토콜

각 단계 졸업 조건 미달 시: 다음 단계 진입 동결 → 원인 라운드(사용 로그·인터뷰) → Bible §0 재판정. "일정이 밀려서 그냥 진행"은 이 문서가 금지하는 유일한 릴리즈 방식이다.
