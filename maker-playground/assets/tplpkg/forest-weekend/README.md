# Forest Weekend — 숲의 주말

3000 × 1000 / Premium Camping Banner / 편집형 템플릿 1종

## 먼저 열기

압축을 푼 뒤 `edit-preview.html`을 브라우저에서 여세요. 인터넷 연결이나 설치 없이 사용할 수 있습니다.

1. 제목 클릭 → 오른쪽에서 문구·글꼴·크기·색상 변경.
2. ‘사진 교체 / 크롭’ 클릭 → 사진 선택 → 확대·가로·세로 위치 조절.
3. 장식 클릭 또는 왼쪽 레이어 선택 → 드래그, 색상 변경, 복제, 삭제, 앞뒤 이동.
4. JSON 저장 → 이후 ‘JSON 열기’로 편집 계속. SVG 저장 → 글자·벡터·사진을 보존한 별도 출력.

**실제 K-Maker 코드 등록·수정은 하지 않았습니다. 현재 K-Maker importer와의 호환성은 미검증이며, `ADAPTER.md`의 객체 매핑이 필요합니다.** 이 패키지의 JSON은 명시적인 편집 객체 계약이며 현재 제품의 내부 API를 추정한 파일이 아닙니다.

## 디자인

짙은 숲색, 따뜻한 아이보리, 절제된 황동색 포인트. 큰 2행 세리프 제목 → 한글 소개 → 예약문의 순으로 읽힙니다. 오른쪽의 벡터 캠핑 풍경은 사진 영역의 기본 콘텐츠입니다. 실사 사진은 기본 포함하지 않았으며, 사진을 넣으면 풍경 객체를 숨깁니다. 사진을 비우면 풍경을 복원합니다. 풍경의 나무·능선·텐트도 독립 객체입니다.

## 파일

| 파일 | 역할 |
|---|---|
| `template.json` | 편집 원본. 텍스트 7개, 사진 슬롯 1개, 도형·벡터 20개 |
| `metadata.json` | 라이브러리 표시용 메타데이터 |
| `layers.json` | 기존 에셋과 동일한 ID·이름·zIndex 기반 레이어 목록 |
| `schema.json` | JSON 구조 검증 규격 |
| `banner.svg` | 실제 text를 유지한 전체 벡터 미리보기 / 교환용 |
| `preview.png` | 미리보기 전용. 편집 원본이 아님 |
| `assets/vectors/` | 개별 벡터 장식 |
| `assets/fonts/` | 한글·영문 폰트 및 SIL OFL 라이선스 |
| `edit-preview.html`, `editor.js` | 이 템플릿의 오프라인 편집 확인 도구 |
| `template-data.js`, `font-data.js` | 로컬 브라우저용 초기 데이터·폰트. JSON과 같은 객체 구조 |
| `ADAPTER.md` | K-Maker 네이티브 객체 가져오기 계약 |
| `validation.json` | 최종 구조·실행 검수 결과 |

## 편집 범위

모든 글자는 문자열을 가진 text 객체이며 path로 변환하지 않았습니다. 내용, 글꼴, 크기, 색상, 정렬, 자간, 행간, 좌표, 회전을 수정합니다. 텍스트 상자를 넘으면 편집 확인 도구가 알려 줍니다. 자동 축소나 자동 줄바꿈은 하지 않으므로 긴 문구는 직접 줄바꿈하거나 크기를 조절하세요.

사진은 독립 슬롯입니다. 교체한 사진은 JSON/SVG에 data URL로 포함해 저장합니다. 기본 cover, 최소 확대 1, 중앙 기준 offsetX/Y를 사용합니다. 빈 가장자리가 나오지 않도록 실제 표시 위치를 제한합니다. 슬롯 위치·크기를 바꾸면 기본 풍경이 함께 따라가며, 기본 풍경의 개별 요소는 따로 편집할 수 있습니다.

전체 크기 변경은 3:1 비율을 유지하며 텍스트·도형·사진을 함께 확대합니다. 가로세로 비율을 달리하는 자동 리디자인은 포함하지 않습니다. 모든 객체는 초기 상태에서 잠금 해제되어 있습니다. `parentId`는 풍경의 사진 슬롯 종속 관계이며, zIndex는 전체 객체 목록 기준입니다.

`template.json`이 원본입니다. 편집 HTML에서 저장한 JSON은 변경 내용을 포함하는 새 원본입니다. 정적인 layers.json·개별 SVG 에셋은 최초 템플릿용이므로 편집본을 가져올 때는 편집본 objects에서 레이어와 경로를 재생성하세요. 전체 SVG를 이미지 1개로 가져오면 네이티브 레이어 편집성을 잃습니다.

## 글꼴과 출력

Cormorant Garamond(영문), Noto Sans CJK KR(한글)를 제공합니다. HTML·SVG에는 한국어 전체 완성형 음절, 한글 자모, 라틴 문자와 주요 문장부호를 포함한 경량 WOFF를 내장했습니다. 원본 OTF/TTF도 제공합니다. 다른 언어·글꼴로 바꿀 때는 해당 글리프를 지원하는 폰트를 선택하세요.

3000 × 1000은 디자인 좌표이며 실물 3m × 1m 또는 DPI를 뜻하지 않습니다. 벡터와 글자는 확대해도 선명합니다. 사진을 넣으면 출력 크기에 충분한 해상도의 사진을 사용하세요. 이 파일은 RGB 디자인 마스터입니다. 실제 인쇄 전 인쇄소의 실물 크기, 여유분·타공 위치, 색상 프로파일에 맞춰 출력 파일을 준비해야 합니다.

벡터는 이번 패키지를 위해 직접 제작했습니다. 폰트는 동봉한 SIL OFL 조건에 따릅니다. 별도 유료 사진이나 원격 이미지 의존성은 없습니다.
