D. R66 에서 잡은 결함 (R65 잠복 · 실측)

사진이 조용히 사라지던 경로 2개
  1. layoutsUsedBy 가 smartVariants 의 layoutPool 을 안 봤다 → Builder 초안에서 Variant 가 선언한 레이아웃이 컴파일 대상에서 빠짐.
  2. variantDefsFromRegistry 가 레이아웃을 id 로만 등재하는데 배치 계획은 별칭으로 지정 → 조회가 빗나가 그 장면 미디어 슬롯이 0 이 되고 사진이 말없이 유실. 세로 8장 중 2장 · 캡션 6장 중 3장 유실을 실측했다.

수정: id·별칭 양쪽 등재 + balancePlan 에 avail 가드(구성이 실제로 컴파일하지 않은 레이아웃은 플래너가 애초에 못 고름). 이중 차단이라 한쪽이 뚫려도 다른 쪽이 막는다.

G. 남은 한계 (정직 기록)

  • 비포&애프터(pairMode)는 쌍 구조가 고정이라 「다른 구성」을 만들지 않는다 — 누르면 그 이유를 문구로 답한다.
  • 모든 장면을 잠그면 재구성을 거부한다(all-locked). 억지로 만들어 잠금을 흉내내지 않는다.
  • Variant 정의는 Builder 화면에서 만들 수 있지만, 조건 축은 사진/쌍 수·방향까지다. 캡션 밀도·영상 비율 조건은 엔진(matchConditions)에는 있으나 UI 노출은 후속.
  • 「자동 구성으로 열기」는 Builder 샘플 미디어로 문서를 만든다. 사용자 실사진으로 들어가는 입구(#/video 갤러리 → 미디어 선택 → 자동 구성)는 후속 라운드 몫.
