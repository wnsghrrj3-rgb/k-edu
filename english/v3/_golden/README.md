2. 개념 슬라이드: 탭(다음 ▶)으로 한 조각씩 등장, 자동흐름 ❌
3. 어순 대조: 글 설명 ❌ → 한↑/영↓ 배치 + 화살표 다이어그램
4. 조립: "I like ___" 틀 고정(위) + 음식 선택지(아래 한 줄, 세로형 카드)

6. 따라 말하기: 정확한 발음 하나, 변주 ❌
