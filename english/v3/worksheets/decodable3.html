3 글에서 a 와 an 을 찾아 △ 하세요 24번 칸에서 고른 짝

It is a goat. It is a boat.  /  I see an ant. It is green.  /  I see snow. It is a big coat.

★ 오늘 기억해요 — 읽기가 끝나면 그림으로 확인! 글이 틀릴 수도 있어요 🔎
학습 안내 · 오늘 읽은 글은 디코더블 — 아이가 이미 배운 소리와 말만으로 이루어진 글입니다(처음 보는 단어 0). 이번 칸에서 달라진 점은 하나, 읽은 다음 그림과 맞춰 본다는 것입니다. 17번 칸이 두 문장을 이어 붙이는 칸이었다면, 오늘은 글이 말한 것과 그림에 실제로 있는 것을 대조합니다. 그래서 Sam 은 일부러 진지하게 틀립니다 — 염소를 가리키며 「It is a boat.」라고 하지요. 아이가 「Sam 이 틀렸어!」라고 잡아내면 오늘 칸의 일을 해낸 것입니다. ④ 의 근거는 언제나 그림이라는 점을 짚어 주세요. Mina 의 「It is green.」 은 일부러 애매하게 둔 문장입니다 — 초록색인 것이 개미인지 잎인지는 그림만 알려 줍니다. ⑤ 는 틀린 문장을 고쳐 쓰는 대신 그림을 보고 바른 단어를 새로 쓰게 했습니다(틀린 꼴을 손으로 베끼지 않도록). an 이 글에서 처음 일합니다 — 「입이 크게 벌어지는 소리 앞에는 an」이라는 24번 칸의 말로만 확인하고, 글자 규칙으로 바꿔 말하지 마세요. 먼저 읽어 주지 마세요. 아이가 읽은 다음 맞았는지 확인해 주는 순서가 이 칸의 전부입니다. 정답 — ② goat · boat · see · snow · green · coat / ③ a goat · a boat · an ant · a big coat / ④ 첫째 ❌ 거짓(Sam 이 가리킨 건 염소) · 둘째 ❌ 거짓(초록색인 건 잎) / ⑤ It is a goat.
