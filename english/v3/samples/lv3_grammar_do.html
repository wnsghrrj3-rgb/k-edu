"너 고양이 좋아해?" — 이걸 영어로 어떻게 말할까요?
답을 그냥 알려주지 않을 거예요.
문장들을 보다 보면 규칙이 스스로 보여요. 🔍
먼저 문장 두 개를 만나러 가요. 다음 →
📖 먼저, 뜻부터
이 문장은 말해주는 문장
말하기
🔊You like cats.
너는 고양이를 좋아해. (친구에게 말해주는 거예요)
🔊가 있는 카드는 누르면 소리가 나요. 한번 눌러서 들어 보세요.
뜻도 같이 읽어 두세요 — 곧 중요해져요!
📖 그리고 이 문장
이건 물어보는 문장
물어보기
🔊Do you like cats?
너 고양이 좋아해? (친구에게 물어보는 거예요)
눌러서 들어 보세요. 끝이 올라가죠? ↗
한국어로는 거의 같은 말인데… 영어 모양은 뭔가 달라졌어요.
🔍 단서 1 — 나란히 놓고 보기
뭐가 달라졌는지 찾는 중…
🔊You like cats.
너는 고양이를 좋아해.
🔊Do you like cats?
너 고양이 좋아해?
두 문장을 번갈아 누르며 들어 보세요.
물어보는 문장에 없던 게 하나 생겼어요. 어디에 생겼는지 눈여겨봐요!
(아직 답 안 해도 돼요 — 단서를 하나 더 봅시다)

🔊Do you run fast?

👀 시범 — 먼저 보여줄게요
규칙으로 문장을 바꾸면 이렇게!
You like dogs.
너는 강아지를 좋아해.
버튼을 누르면 Do가 날아와 붙는 걸 보여줄게요.
🛠 이제 내 차례 ①
"너 강아지 좋아해?"
영어로 바르게 물어본 것은?
You like dogs?
Do가 없어요 — 그냥 말하기 문장에 ?만 붙였네요
Do you like dogs?
맨 앞에 Do!
Like you dogs?
단어 순서가 뒤집혔어요
방금 본 시범을 떠올려요 — 맨 앞에 뭐가 왔죠?
🛠 이제 내 차례 ②
"걔네 빨리 달려?"
이번엔 새 문장으로!
They run fast. (그 애들은 빨리 달려.) — 를 물어보는 문장으로:
Do they run fast?
They do run fast?
Do의 자리가 틀렸어요 — 맨 앞이에요!
Run they fast?
단어 순서가 뒤집혔어요
규칙은 똑같아요 — 어떤 문장이든!
⭐ 오늘 내가 발견한 규칙
💡 영어로 물어볼 땐
문장 맨 앞에 Do를 붙인다!
한국어: 끝을 올린다 ↗ / 영어: 앞에 Do + 끝도 올린다 ↗
선생님이 알려준 게 아니라 내가 단서로 찾아낸 규칙이에요.
어른들은 이런 문장을 '의문문'이라고 불러요 — 이름은 나중에, 규칙이 먼저!
