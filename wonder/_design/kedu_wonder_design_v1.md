## 1. 지켜야 할 것

### 1-1. 지난 실패에서 온 규칙

| 준호가 한 말 | 규칙 |
|---|---|
| 「뭘 해야 하지만 든다」「어디로 가라는지 모르겠다」 (케이월드) | **장면 하나 = 손잡이 하나 + 목표 하나.** 돌아다니는 넓은 터를 만들지 않는다. 그믐밤 방식. |
| 「행동에 결과가 없다」 | 손잡이를 움직이면 **1초 안에 화면 전체가** 달라진다. |
| 「맵이 좁아 배경이 별거 아닌 것처럼」 | 좁은 터에 배경을 세우지 않는다. **밤하늘·우주·심해·구름 속**처럼 끝이 안 보이는 곳만 고른다(열두 장면 전부 그렇다). |
| 「80년대 갤로그 수준」 | 본보기 장면 하나로 **그림 수준을 먼저 준호 눈으로 확인**한다. 통과 못 하면 나머지를 만들지 않는다. |
| 「처음은 강렬한데 전체로 가면 흐지부지」 | 열두 개를 한꺼번에 벌이지 않는다. 하나 끝 → 준호 확인 → 다음. |
| 「그림이 좋아지면 크롬북에서 안 돌 것」 | 화질 등급 셋 자동(과학실 설계 6-4 와 같은 한도). 어두운 장면이라 싸게 화려하다. |
| 「모든 게 모션일 필요 없다」 | **터치·마우스가 기본.** 케이모션 손은 맞는 장면에만 얹는다(1·9·6). |
| 「놀이인지 학습인지 구분이 안 가게」 | 설명을 먼저 띄우지 않는다. 해 본 **뒤에** 까닭 두 문장. |

### 1-2. 블렌더가 하는 일과 코드가 하는 일 (솔직하게)

이 열두 장면의 화려함은 **빛·입자·셰이더**에서 나온다. 그것은 코드가 한다. 블렌더는 그 빛이 **비칠 단단한 것**과 **미리 구울 그림**을 만든다. 둘을 섞어야 실사처럼 보인다.

| 블렌더(bpy)가 만든다 | 코드(Three.js)가 만든다 |
|---|---|
| 손에 잡히는 물건: 발사통, 잠수정 조종석, 우주선 창틀, 현미경, 조절 손잡이판 | 불꽃·불티·연기·안개·번개 |
| 행성·태양·화산 지형의 표면 그림(블렌더에서 무늬를 만들어 펼친 그림으로 구움) | 휘는 빛(블랙홀), 오로라 커튼, 물속 빛줄기 |
| 생물과 덩어리 모양: 해파리·아귀·물곰·적혈구·결정·얼음 덩어리(움직임 뼈대·모양 키 포함) | 수만 개를 한 번에 그리기(고리 얼음, 적혈구, 바다 눈) |
| 미리 쪼갠 조각(행성 충돌 파편) | 용암 흐름, 구름 덩어리, 결정이 자라는 차례 |
| 주변 360° 배경(밤 강변, 별 하늘, 심해 어둠)과 조명 굽기 | 빛 번짐·노출·색 보정 |

**위험한 곳**: 생물(3·11·12). 받아 온 동물 모델이 어색했던 전례가 있다. 그래서 생물은 **어둠 속에서 스스로 빛나는 것, 반투명한 것, 현미경 속 것**만 골랐다. 털·얼굴·걷는 다리가 없어 어색함이 덜 드러난다. 그래도 생물이 가장 늦게, 가장 조심해서 만들 것이다.

### 1-3. 그림 약속 (전 장면 공통)

- 방·물건은 과학실 설계 6-2·6-5 를 그대로 따른다: 실제 치수, 모든 모서리 깎기, 흠 넣기, 빈 점 이름 약속, 기준 그림 먼저.
- **어두운 바탕 + 스스로 빛나는 주인공.** 열두 장면 모두 배경이 어둡다. 빛 번짐 하나로 화려해지고, 그릴 것이 적어 크롬북이 버틴다.
- **크기를 느끼게 하는 것 하나를 꼭 둔다**: 불꽃 아래 다리와 건물, 태양 옆 지구, 고리 속 얼음 옆의 우주선, 결정 옆의 연필. 크기를 견줄 것이 없으면 장관이 장난감이 된다.
- **창틀을 둔다**: 우주·심해·혈관은 맨눈이 아니라 조종석 창 너머로 본다. 창틀·계기·유리 얼룩이 화면 가장자리에 걸리면 "내가 거기 있다"가 된다(블렌더 몫).
- 화면 위 글자는 의뢰 한 줄뿐. 수치는 조종석 계기가 보여 준다.
- 색 보정은 장면마다 한 가지 색 온도로 통일(불꽃놀이 = 남색 밤 + 따뜻한 불빛).

### 1-4. 한 장면의 흐름 (전 장면 공통)

```
들어옴(5초 장관, 손대지 않아도 이미 멋짐) → 손잡이 하나가 빛남 → 만져 봄(바로 바뀜)
   → 의뢰 1(쉬움) → 의뢰 2(생각) → 의뢰 3(뒤집힘) → 까닭 두 문장 → 자유 → 도감
```

- **들어오자마자 5초가 승부**다. 설명·시작 단추 없이 장관이 먼저 돌아가고 있어야 한다.
- 손잡이는 **둘, 많아야 셋.** 조종석의 진짜 물건(레버·다이얼·밸브)으로 만든다. 화면에 뜬 막대 UI 를 쓰지 않는다.
- 의뢰 셋은 **쉬움 → 손잡이 둘을 같이 써야 함 → 예상이 뒤집힘** 차례.
- **자유**에서는 손잡이의 한도가 풀린다(말도 안 되게 큰 불꽃, 태양만 한 행성). 여기서 발견한 것이 도감에 찍힌다. 도감 빈칸은 그림자로만 보인다.
- 저장은 첫 판에는 없다(과학실 설계 8-2 와 같음).

## 2. 열두 장면

각 장은 같은 틀이다: 약속 / 무대 / 손잡이 / **이렇게 하면 → 이렇게 된다** / 의뢰 / 긴장과 깊이 / 까닭 / 블렌더·코드 / 그림과 소리의 급소.

---

### 장면 1. 불꽃놀이 공장 ★ 본보기 (가장 먼저 만든다)

**약속**: 내가 채운 불꽃이 진짜 밤하늘에서 터진다.

**무대**: 밤 강변. 앞에 작업대(둥근 불꽃 껍질 반쪽이 열려 있다)와 발사통 다섯 개. 멀리 강 건너 도시 불빛과 다리, 강물에 비치는 불빛. 컷 둘 — 작업대 컷(채우기) / 하늘 컷(올려다보기, 강물 반사 포함).

**손잡이**: ① 색 가루 통(작업대에 여덟 개) ② 껍질 안에 알갱이를 **놓는 자리** ③ 발사통 레버(쥐고 당겼다 놓기 — 케이모션 손이면 팔을 위로 휙).

**이렇게 하면 → 이렇게 된다**

| 한 일 | 하늘에서 |
|---|---|
| 스트론튬 가루 | **빨강** |
| 칼슘 | 주황 |
| 나트륨 | 노랑(유난히 밝다) |
| 바륨 | 초록 |
| 구리 | 청록·파랑 |
| 스트론튬 + 구리를 섞음 | 보라 |
| 알루미늄·마그네슘 부스러기 | 눈부신 흰 불티, 지지직 반짝임 |
| 쇳가루·숯가루 | 금빛 꼬리가 길게 늘어져 **버들**처럼 흘러내림 |
| 알갱이를 껍질 안에 **공 모양으로 고르게** | 둥근 국화 |
| **한 줄 고리로** | 하늘에 고리 |
| **하트 모양으로 놓음** | 하트(보는 방향에 따라 납작한 선으로 보이기도 — 그래서 여러 발을 쏜다) |
| 안쪽·바깥쪽 두 겹으로 다른 색 | 속 색이 먼저, 겉 색이 나중에 — 두 겹 꽃 |
| 큰 껍질 | 더 높이, 더 크게, **소리가 더 늦게** |
| 작은 껍질 | 낮게, 빨리 |
| 가운데 터뜨림 약을 빼먹음 | 올라가다 불발 — 풍덩 강에 떨어짐 |
| 알갱이를 한쪽에 몰아 넣음 | 한쪽으로 찌그러진 꽃 |
| 다섯 통을 박자 맞춰 연달아 | 겹겹이 터지는 피날레 |

**의뢰**: ① 초록 국화를 쏘아라 ② 주문서 그림(빨간 속 + 금빛 버들 겉, 두 겹)과 똑같이 ③ 하늘에 웃는 얼굴을(고리 + 점 둘 + 호 — 알갱이 놓는 자리가 그대로 모양이 된다는 걸 알아야)

**긴장과 깊이**: 쏘고 나면 못 고친다. 올라가는 2초의 휘이익 — 터지기 전의 그 조용함. 주문서와 견주어 별 셋. **자유**: 내 불꽃 쇼 짜기(다섯 통에 채워 놓고 순서대로 쏘면 강 건너 구경꾼 환호 소리가 커진다). 도감: 색 여덟 × 모양 여덟.

**까닭**: 「금속마다 뜨거워지면 내는 빛의 색이 달라요. 불꽃놀이의 색은 물감이 아니라 금속이에요.」 / 「껍질 속에 알갱이를 놓은 모양 그대로 하늘에서 퍼져요.」 / 「번쩍하고 나서 한참 뒤에 쾅 해요. 빛은 순식간에 오는데 소리는 1초에 운동장 세 바퀴쯤밖에 못 와요.」

**넣지 않는 것**: 화약의 성분·비율·만드는 법. 화면에는 「색 가루」「터뜨림 약」「도화선」이라는 이름의 이미 만들어진 재료만 있다.

**블렌더**: 강변 야경 360° 배경(도시 실루엣·다리·가로등, 조명 구움), 작업대·껍질 반쪽·가루 통·발사통·레버, 강 수면 판. **코드**: 불꽃 입자(알갱이마다 궤적·중력·공기 저항·꼬리·색 변화·사그라짐), 빛 번짐, 강물 반사(하늘을 뒤집어 흐린 그림으로), 터질 때 구름과 연기가 불빛에 물듦, 소리 지연.

**급소**: 불티가 **점이 아니라 꼬리 달린 선**이어야 한다. 터진 뒤 남는 **연기가 다음 불꽃 빛에 비치는 것**이 실사와 장난감을 가른다. 강물에 일렁이며 비치는 반사. 소리는 낮은 "쿵"이 가슴에 오고 산에 메아리친다. 구경꾼의 "우와".

### 장면 2. 오로라

**약속**: 내가 분 태양 바람이 하늘에 빛의 커튼을 친다.

**무대**: 눈 덮인 북쪽 호숫가의 밤. 침엽수 실루엣, 오두막 불빛 하나, 얼음 호수에 비치는 하늘. 컷 둘 — 땅에서 올려다보기 / 우주에서 내려다보기(지구 극지방에 빛나는 고리).

**손잡이**: ① 태양 바람 세기(조종판 레버) ② 고도 다이얼(커튼이 생기는 높이) ③ 컷 바꾸기(망원경 ↔ 위성 창).

| 한 일 | 일어나는 일 |
|---|---|
| 바람 약함 | 지평선 가까이 희미한 초록 띠 |
| 바람 보통 | 초록 커튼이 하늘을 가로질러 **너울너울** 흔들린다 |
| 바람 셈 | 커튼이 머리 위까지 번지고 주름이 빨라진다. 아래 가장자리에 **분홍 테** |
| 바람 폭풍 | 하늘 전체가 덮이고 위쪽이 **빨갛게**, 사방에서 머리 위 한 점으로 모이는 빛살(왕관) |
| 고도 높임 | 초록 → 빨강(높은 곳의 산소) |
| 고도 낮춤 | 보라·분홍(질소) |
| 우주 컷 | 극지방을 두른 빛나는 **고리**. 바람이 세질수록 고리가 굵어지고 남쪽으로 내려온다 |
| 지구 자석을 끔(자유) | 오로라가 사라지고 바람이 땅까지 그대로 온다 |
| 목성으로 바꿈(자유) | 훨씬 큰 푸른 오로라 |

**의뢰**: ① 초록 커튼을 머리 위까지 ② 분홍 테를 만들어라(세기와 고도 둘 다) ③ 우리나라에서도 보이게 하라(폭풍까지 올려 고리를 남쪽으로 — 실제로 아주 드물게 일어난 일)

**긴장과 깊이**: 조용한 장면이다. 긴장 대신 **사진 찍기** — 가장 멋진 순간을 찍어 견본 사진과 견준다(커튼은 계속 변해 같은 모양이 다시 안 온다). 도감: 모양 일곱(띠·커튼·주름·빛살·왕관·맥동·붉은 하늘).

**까닭**: 「태양에서 날아온 알갱이들이 지구 자석에 끌려 북쪽과 남쪽 끝으로 몰려요. 거기서 공기와 부딪쳐 빛나요.」 / 「초록과 빨강은 산소가, 보라와 분홍은 질소가 내는 빛이에요.」

**블렌더**: 호숫가 360° 배경(눈·나무·오두막·별), 조종판, 우주 컷의 지구(밤 쪽 도시 불빛 그림 구움). **코드**: 오로라 커튼(휜 띠 여러 겹 + 세로 빛살 무늬 흐름 + 높이에 따른 색), 호수 반사, 눈밭이 오로라 색으로 물듦.

**급소**: 커튼의 **세로 줄무늬**와 느린 너울. 색이 형광이 아니라 살짝 탁한 초록. 눈밭과 나무 꼭대기에 번지는 초록빛. 소리는 거의 없다 — 바람, 눈 밟는 소리, 먼 늑대.

### 장면 3. 깊은 바다

**약속**: 햇빛이 닿지 않는 곳에는 스스로 빛나는 것들이 산다.

**무대**: 잠수정 조종석(둥근 창, 깊이 바늘, 압력 바늘, 탐조등 스위치, 바깥에 매단 스티로폼 컵). 아래로만 내려간다. 다섯 층: 햇빛 층(0~200m) → 어스름 층(~1,000m) → 캄캄한 층(~4,000m) → 깊은 바닥(~6,000m) → 바다 골짜기 바닥(~11,000m).

**손잡이**: ① 내려가기·멈추기 레버 ② 탐조등 켜고 끄기·방향 ③ 사진 단추.

| 한 일 | 일어나는 일 |
|---|---|
| 내려간다 | 물색이 하늘색 → 파랑 → 남색 → 검정. 창 위쪽의 햇빛 무늬가 사라진다 |
| 50m 쯤 | 창밖 빨간 물고기가 **검게** 보인다(빨간빛이 먼저 사라진다). 탐조등을 켜면 다시 빨갛다 |
| 어스름 층에서 탐조등을 **끈다** | 어둠 속에 푸른 점들이 하나둘 — 빛나는 해파리, 등불 물고기 떼 |
| 탐조등을 켠다 | 빛나던 것들이 달아나고 **바다 눈**(하얀 부스러기)만 흩날린다 |
| 캄캄한 층에서 끄고 기다린다 | 초롱아귀의 초롱이 다가온다. 켜면 — 이빨 |
| 창을 톡톡 두드린다 | 둘레의 작은 것들이 한꺼번에 번쩍 푸른 불빛(놀라면 빛난다) |
| 계속 내려간다 | 매단 스티로폼 컵이 **점점 쪼그라든다.** 선체가 끼익 운다 |
| 깊은 바닥 | 뜨거운 물 굴뚝에서 **검은 연기**, 둘레에 하얀 게와 붉은 관 벌레 숲 |
| 바닥에 내린다 | 고래 뼈대와 거기 모인 것들 / 흙먼지가 천천히 인다 |
| 너무 빨리 내려간다 | 압력 경보, 창에 금 소리 → 자동 멈춤(사고 기록) |

**의뢰**: ① 빛나는 것 셋을 찍어라(불을 꺼야 보인다는 걸 알아야) ② 해도 없는 곳의 생물 마을을 찾아라(굴뚝) ③ 컵을 엄지만 하게 만들어 돌아오라(가장 깊은 곳까지 — 전지가 닳는다, 탐조등을 아껴야)

**긴장과 깊이**: 전지. 탐조등을 켜면 닳고, 끄면 캄캄하다. **끄고 기다리는 어둠**이 이 장면의 심장이다. 무엇이 다가오는지 모른다. 도감: 생물 스물(층마다 넷), 드문 것(대왕오징어는 아주 가끔 창밖을 스쳐 지나간다).

**까닭**: 「햇빛은 200m 아래로는 거의 못 내려가요. 그 아래 생물들은 제 몸으로 빛을 만들어요 — 먹이를 꾀고, 짝을 찾고, 적을 놀라게 하려고.」 / 「깊이 들어갈수록 위에 쌓인 물이 무겁게 눌러요. 가장 깊은 곳은 엄지손톱 위에 자동차 한 대가 올라선 만큼.」

**블렌더**: 조종석(창틀·계기·스위치·긁힌 유리), 스티로폼 컵(모양 키), 생물들(해파리·등불 물고기·초롱아귀·뱀파이어오징어·덤보문어·관 벌레·게 — 뼈대와 헤엄 동작, 빛나는 자리 표시), 굴뚝 지형, 고래 뼈. **코드**: 깊이에 따른 물색과 흐림, 햇빛 줄기, 바다 눈, 탐조등 빛 기둥(뿌연 원뿔), 빛나는 무늬의 깜박임, 떼 지어 헤엄.

**급소**: **어둠이 진짜 어두워야** 한다(화면이 거의 검어도 겁내지 않는다). 탐조등 원뿔 속에서만 떠다니는 부스러기. 생물은 가까이 와서 창 앞을 스칠 때만 자세히 보이게(멀리서는 빛 점). 소리: 선체 삐걱임, 숨소리 같은 공기 장치, 멀리 고래 울음, 깊이 바늘의 딸깍.

### 장면 4. 블랙홀

**약속**: 빛조차 못 빠져나오는 곳에 별을 던져 본다.

**무대**: 우주선 창 너머. 가운데 검은 원, 둘레에 불타는 원반(안쪽은 흰 푸른빛, 바깥은 주황), 뒤의 별들이 원 둘레에서 **휘어 고리처럼** 보인다. 컷 둘 — 멀리서(전체) / 가까이(원반 스치기).

**손잡이**: ① 던질 것 고르기(별·행성·우주선·시계 탑재 탐사선) ② 던지는 **방향과 세기**(끌었다 놓기) ③ 거리 레버(다가가기).

| 한 일 | 일어나는 일 |
|---|---|
| 곧장 던진다 | 점점 빨라지며 빨려 들어간다. 가까워질수록 **국수처럼 늘어난다** |
| 비스듬히, 알맞은 세기 | 블랙홀 둘레를 **돈다**(궤도) |
| 비스듬히, 너무 약하게 | 나선을 그리며 원반에 섞여 빛난다 |
| 비스듬히, 아주 세게 | 휘었다가 **튕겨 나가듯** 반대쪽으로 날아간다 |
| 별을 가까이 지나가게 | 별이 찢겨 긴 빛줄기가 되어 원반으로 감긴다 |
| 시계 단 탐사선을 가까이 | 탐사선 시계가 **내 시계보다 느리게** 간다. 가까울수록 더 |
| 탐사선이 검은 원 가장자리에 닿음 | 멈춘 듯 붉어지며 흐려진다 — 들어가는 걸 끝내 못 본다 |
| 우주선을 다가가게 | 뒤의 별들이 더 심하게 휜다. 원반의 뒤쪽이 **위아래로 접혀** 보인다 |
| 블랙홀 뒤로 별 하나를 지나가게 | 별이 둘로, 그러다 **고리**로 보인다 |
| 블랙홀을 키운다(자유) | 검은 원이 커지는데 가장자리에서의 늘어남은 오히려 순해진다 |

**의뢰**: ① 행성을 블랙홀 둘레에 세 바퀴 돌려라 ② 탐사선 시계를 내 시계의 절반 빠르기로(가까이, 그러나 안 빠지게 궤도에) ③ 블랙홀 뒤에 숨은 별을 찾아라(휜 빛으로 — 고리가 생기는 자리)

**긴장과 깊이**: 던지는 손맛(세기·방향이 조금만 달라도 결과가 다르다). 궤도에 올린 것이 몇 바퀴째에 떨어지나 조마조마. 자유: 블랙홀 둘, 서로 도는 블랙홀에 별 던지기.

**까닭**: 「블랙홀은 아주 많은 것이 아주 작은 곳에 뭉친 거예요. 끌어당기는 힘이 너무 세서 빛도 못 나와요. 그래서 까맣게 보여요.」 / 「그 둘레에서는 빛도 휘고 시간도 느리게 가요.」 / 「머리 쪽보다 발 쪽을 더 세게 당겨서 길게 늘어나요.」

**블렌더**: 우주선 창틀·조종판·던지는 장치, 던질 것들(별은 빛나는 공, 행성은 표면 그림 구움, 탐사선 모델 + 시계판), 별 하늘 360° 그림. **코드**: 블랙홀 셰이더(화면의 배경 빛을 검은 원 둘레에서 휘게 + 원반과 그 접혀 보이는 상), 궤도 계산(끌림의 법칙 그대로), 늘어남(물체를 끌리는 방향으로 늘림), 시계 느려짐.

**급소**: 원반은 한쪽이 더 밝다(다가오는 쪽). 휘는 별빛이 우주선을 움직일 때 **미끄러지듯 흘러야** 진짜 같다. 소리는 우주라 없다 — 대신 우주선 안의 낮은 웅 소리, 계기 삑, 그리고 다가갈수록 낮아지는 저음.

### 장면 5. 태양 가까이

**약속**: 매일 보던 그 태양이 사실은 이런 것이다.

**무대**: 탐사선 창. 화면을 가득 채운 끓는 표면(쌀알 무늬가 꿈틀), 가장자리에서 솟는 불기둥, 검은 점들. 컷 셋 — 멀리(태양과 지구가 한 화면: 지구는 점) / 표면 위 / 가장자리(불기둥 옆).

**손잡이**: ① 색유리 다이얼(보통 빛 / 붉은 빛 / 자외선 — 같은 태양이 다르게 보인다) ② 거리 레버 ③ 지구 놓기(끌어다 옆에 대 보기).

| 한 일 | 일어나는 일 |
|---|---|
| 색유리 없이 본다 | 화면이 하얗게 날아간다(가리개 필요) |
| 보통 빛 | 노란 공, 검은 점들(흑점) |
| 붉은 빛 | 표면의 꿈틀거리는 쌀알 무늬, 가장자리의 붉은 불기둥 |
| 자외선 | 표면에서 고리 모양으로 솟아 되돌아오는 **빛의 다리**들 |
| 지구를 불기둥 옆에 댄다 | 불기둥 하나가 **지구 여러 개** 높이 |
| 지구를 흑점 위에 댄다 | 흑점 하나에 지구가 쏙 들어간다 |
| 지구를 한 줄로 늘어놓는다 | 태양 지름에 **109개** |
| 흑점에 다가간다 | 주변보다 어두울 뿐, 여전히 눈부시게 뜨겁다(온도계: 주변 5,500도, 흑점 4,000도쯤) |
| 꼬인 빛의 다리를 기다린다 | 툭 끊어지며 **폭발**(플레어) — 알갱이 구름이 날아간다 → 장면 2(오로라)로 이어짐 |
| 표면에서 빛 한 줄기를 쏜다 | 지구까지 가는 시계: **8분 20초** |

**의뢰**: ① 지구가 들어가는 흑점을 찾아라 ② 폭발의 순간을 찍어라(자외선으로 꼬인 다리를 찾아 기다려야) ③ 태양에 지구가 몇 개 늘어서는지 세어라

**까닭**: 「태양은 불타는 게 아니라 속에서 작은 알갱이들이 합쳐지며 빛을 내요. 땅이 없고 전부 뜨거운 기체예요.」 / 「흑점은 식은 게 아니라 둘레보다 덜 뜨거워서 어둡게 보일 뿐이에요.」

**블렌더**: 탐사선 창틀·색유리 다이얼, 지구 모델, 태양 표면 무늬 그림 여러 장(쌀알·흑점·밝은 얼룩을 블렌더 무늬로 구움). **코드**: 표면 꿈틀거림(무늬 그림 여러 장을 흐르게 섞음), 불기둥·빛의 다리(휜 띠 + 흐르는 빛), 가장자리 빛남, 폭발.

**급소**: 표면이 **쉬지 않고 끓어야** 한다(멈춘 그림이면 죽는다). 가장자리로 갈수록 살짝 어두워지는 것. 불기둥은 천천히 — 너무 빠르면 작아 보인다. 소리: 낮게 우르릉거리는 가상의 소리(「진짜 우주에서는 안 들려요」 한 줄).

### 장면 6. 달 만들기

**약속**: 행성 둘을 부딪쳐서 달을 만든다.

**무대**: 우주 공간, 가운데 어린 지구(겉이 아직 붉게 달아오른 곳이 있다). 화면 한쪽에서 다른 행성을 던진다.

**손잡이**: ① 던질 행성의 크기 ② 방향(정면 ↔ 스치듯) ③ 빠르기. 던진 뒤에는 ④ 시간 빨리 감기 다이얼.

| 한 일 | 일어나는 일 |
|---|---|
| 작은 것, 정면 | 큰 구덩이와 번쩍, 파편 조금 → 다시 떨어짐. 달 없음 |
| 화성만 한 것, **비스듬히**, 알맞게 | 겉이 녹아 튀어 올라 **빛나는 고리** → 감으면 뭉쳐서 **달 하나** |
| 같은 것, 정면 | 둘이 합쳐져 큰 행성 하나, 달 없음 |
| 같은 것, 너무 빠르게 | 둘 다 부서져 파편 구름 |
| 아주 스치듯 | 빗나갔다 돌아와 두 번째 충돌 |
| 조금 다르게 비스듬히 | **달 둘**(나중에 하나는 떨어지거나 달아난다) |
| 얼음 행성을 던짐(자유) | 바다가 생긴다 |
| 달이 생긴 뒤 감기 | 달이 처음엔 **하늘의 반을 덮을 만큼** 가깝다가 점점 멀어진다. 지구 겉이 식어 파랗게 |

**의뢰**: ① 달 하나를 만들어라 ② 지금 우리 달만 한 크기로 ③ 달 둘을 만들어 둘 다 살아남게

**긴장과 깊이**: 부딪치는 순간의 느린 동작. 결과를 감아 보기 전까지 모른다. 같은 조건이 거의 없어 매번 다르다. 도감: 결과 여덟(달 없음·달 하나·달 둘·고리·합체·박살·바다 행성·되튐).

**까닭**: 「아주 옛날, 화성만 한 행성이 어린 지구와 비스듬히 부딪쳤어요. 튀어나온 조각들이 뭉쳐 달이 됐다고 과학자들은 생각해요.」 / 「그래서 달의 돌은 지구의 돌과 닮았어요.」

**블렌더**: 행성 표면 그림(어린 지구·바위 행성·얼음 행성), **미리 쪼갠 조각**(겉껍질 조각 큰 것·작은 것), 녹은 겉면 그림. **코드**: 끌림 계산(조각 수백 개), 부딪친 자리의 달아오름과 식음, 뭉치기, 빨리 감기.

**급소**: 부딪친 자리에서 **빛나는 물결**이 행성 겉을 타고 퍼지는 것. 조각이 식으며 흰색 → 주황 → 검게. 크기 견줄 것: 화면 구석의 지금 달 크기 그림자.

---

### 장면 7. 토성 고리 속

**약속**: 멀리서는 레코드판, 들어가면 얼음 눈보라.

**무대**: 작은 우주선 조종석. 창밖에 화면을 가득 채운 토성과 고리. 내려가면 고리가 띠 → 줄무늬 → 알갱이 → 집채만 한 얼음 덩어리들.

**손잡이**: ① 조종 손잡이(위아래·좌우 살짝) ② 다가가기 레버 ③ 집게 팔(얼음 덩어리 하나 집어 오기).

| 한 일 | 일어나는 일 |
|---|---|
| 멀리서 본다 | 매끈한 띠, 가운데 검은 틈 |
| 다가간다 | 띠가 수천 줄의 가는 줄무늬로 갈라진다 |
| 더 다가간다 | 줄무늬가 **반짝이는 알갱이의 강**이 된다 |
| 고리 안으로 | 눈송이만 한 것부터 집채만 한 얼음 덩어리가 **모두 같은 방향으로** 천천히 흐른다. 서로 살짝 부딪치고 붙었다 떨어진다 |
| 고리를 옆에서 본다 | 거의 **안 보인다** — 종이 한 장처럼 얇다 |
| 검은 틈으로 간다 | 텅 비었다. 저 멀리 작은 달 하나가 틈을 쓸고 지나간다 |
| 덩어리 하나를 집게로 집어 와 비춘다 | 거의 순수한 얼음(창 안 표본 통에서 녹는다) |
| 덩어리를 세게 민다 | 다른 것과 부딪쳐 부서지고, 한참 뒤 흐름에 다시 섞인다 |
| 토성 쪽을 본다 | 고리가 토성에 드리운 줄무늬 그림자. 극에는 육각형 구름 |
| 토성을 큰 물통에 넣어 본다(자유) | **둥둥 뜬다** |

**의뢰**: ① 고리가 사라지는 자리를 찾아라(옆에서 보기) ② 부딪치지 않고 고리를 뚫고 반대편으로(덩어리 사이로 조종) ③ 틈을 만든 범인을 찾아라(작은 달)

**긴장과 깊이**: ②가 이 장면의 놀이다 — 얼음 사이를 누비는 조종. 부딪치면 선체 긁힘·경보. 

**까닭**: 「토성의 고리는 판이 아니라 수없이 많은 얼음 조각이에요. 전부 토성 둘레를 돌고 있어요.」 / 「폭은 지구를 스무 개 넘게 늘어놓을 만큼 넓은데, 두께는 아파트 몇 층 높이밖에 안 돼요.」

**블렌더**: 조종석, 집게 팔, 얼음 덩어리 모양 열 가지(울퉁불퉁·서리·금), 토성 표면 그림과 고리 띠 그림(줄무늬·틈). **코드**: 거리에 따른 세 단계 바꿔치기(띠 그림 → 줄무늬 → 실제 덩어리 수만 개 한 번에 그리기), 햇빛이 얼음에 반짝임, 토성 그림자 속으로 들어갈 때 어두워짐.

**급소**: **단계가 바뀌는 순간이 티 나지 않게**(이 장면의 전부). 얼음마다 햇빛 받는 쪽만 눈부시고 반대쪽은 칠흑. 수만 개가 한 방향으로 느리게 흐르는 웅장함. 소리: 선체에 잔 얼음이 부딪는 사락사락.

### 장면 8. 화산 속

**약속**: 어떤 화산은 흐르고 어떤 화산은 터진다. 그 차이를 내가 만든다.

**무대**: 화산 단면이 보이는 관측소(산 옆구리를 잘라 본 듯 — 아래 마그마 방, 올라오는 길, 꼭대기). 컷 셋 — 단면 / 산 밖 멀리서 / 용암 가까이(내열 무인기).

**손잡이**: ① 끈적임 레버(묽게 ↔ 끈적하게) ② 기체 양 밸브 ③ 밀어 올리는 힘.

| 한 일 | 일어나는 일 |
|---|---|
| 묽음 + 기체 적음 | 주황 용암이 **강처럼 줄줄** 흘러내린다. 산은 넓고 완만해진다 |
| 묽음 + 기체 많음 | 꼭대기에서 **불 분수**가 솟는다 |
| 끈적 + 기체 적음 | 꼭대기에 용암 **혹**이 천천히 부푼다 |
| 끈적 + 기체 많음 | 길이 막혀 압력 바늘이 오르다 — **대폭발.** 재 기둥이 구름 위까지, 번개가 친다 |
| 재 기둥이 무너짐 | 잿빛 구름이 산비탈을 **쏟아져 내린다**(가장 위험한 것) |
| 용암이 바다에 닿음 | 김 구름, 물속에서 **베개 모양**으로 굳는다 |
| 용암이 숲에 닿음 | 나무가 타고, 굳은 뒤 나무 모양 구멍이 남는다 |
| 흐르던 용암 겉이 굳음 | 속은 계속 흘러 **용암 동굴**이 된다(무인기로 들어가 봄) |
| 무인기를 용암 호수 위로 | 검은 껍질이 갈라지며 속의 주황빛이 드러나고 다시 덮인다 |
| 다 끝난 뒤 빨리 감기 | 재 위에 풀이 돋고 숲이 돌아온다 |

**의뢰**: ① 용암 강을 바다까지 흘려보내라 ② 불 분수를 뿜어라 ③ 산꼭대기를 날려 버려라(끈적 + 기체 — 그리고 왜 묽은 용암으로는 안 되는지)

**긴장과 깊이**: 압력 바늘. 끈적한 쪽은 **오래 조용하다가** 한 번에 터진다 — 기다리는 동안 땅이 떨리고 꼭대기가 부푼다. 도감: 분출 여섯, 굳은 용암 모양 다섯.

**까닭**: 「땅속 깊은 곳의 녹은 돌이 마그마예요. 그 속에 기체가 녹아 있어요. 사이다와 같아요.」 / 「묽으면 기체가 쉽게 빠져나가 조용히 흘러요. 끈적하면 기체가 갇혔다가 한꺼번에 터져요.」

**블렌더**: 화산 지형(산·단면·바다·숲 — 높낮이 그림과 겉 그림 구움), 관측소 창과 조종판, 무인기, 굳은 용암 덩어리·베개 용암·나무 구멍 모양. **코드**: 용암 흐름(지형을 타고 내려가는 빛나는 겉 + 식어 가는 검은 껍질), 불 분수(불티 부품), 재 기둥(구름 덩어리), 쏟아지는 잿빛 구름, 재 구름 속 번개, 김.

**급소**: 용암의 **겉은 검고 갈라진 틈만 빛나야** 한다(통째로 주황이면 주스 같다). 밤으로 두면 훨씬 좋다. 재 기둥은 아주 느리게(커 보이게). 소리: 땅 울림, 유리 깨지는 듯한 용암 껍질 소리, 폭발의 충격.

### 장면 9. 폭풍 만들기

**약속**: 맑은 하늘에서 시작해 내 손으로 번개 구름을 키운다.

**무대**: 넓은 평원 위 관측 차량(지붕 창). 지평선까지 트인 하늘, 멀리 농가와 풍차(크기 견줌). 컷 둘 — 땅에서 / 구름 높이에서.

**손잡이**: ① 땅 데우기(햇볕) ② 물기(습한 공기 불어넣기) ③ 엇갈린 바람(위와 아래 바람 방향 다르게). 케이모션 손이면 두 팔로 공기를 **밀어 올리고 비튼다.**

| 한 일 | 일어나는 일 |
|---|---|
| 데우기만 | 아지랑이, 구름 없음 |
| 데우기 + 물기 조금 | 뭉게구름 몇 조각 |
| 데우기 + 물기 많이 | 구름이 **탑처럼 솟아** 꼭대기가 모루 모양으로 퍼진다. 아래가 시커메진다 |
| 계속 키움 | 구름 속이 번쩍거리다 **번개**가 땅으로. 비 기둥 |
| 더 키움 | 우박(차 지붕을 때리는 소리), 돌풍 |
| 여기에 **엇갈린 바람** | 구름 전체가 천천히 **돈다.** 아래로 벽 같은 구름이 처진다 |
| 도는 구름을 계속 키움 | 깔때기가 내려와 땅에 닿는다 — **토네이도.** 흙먼지 기둥 |
| 토네이도가 풍차를 지남 | 풍차가 빨려 올라간다(사람·동물은 없다) |
| 데우기를 끔 | 구름이 힘을 잃고 흩어진다. 무지개 |
| 물기 없이 엇갈린 바람만 | 먼지 회오리 작은 것 |

**의뢰**: ① 번개를 열 번 쳐라 ② 골프공만 한 우박을 만들어라(구름 꼭대기를 더 높이 — 우박은 구름 속을 여러 번 오르내리며 큰다) ③ 토네이도를 농가에 닿지 않게 비켜 가게 하라(만드는 것보다 **모는 것**이 어렵다)

**긴장과 깊이**: 키운 폭풍은 **내 말을 잘 안 듣는다.** 손잡이를 놓아도 한동안 혼자 자란다. 번개는 어디 칠지 모르고(높은 것에 잘 친다 — 풍차), 차량 가까이 치면 화면이 하얗게.

**까닭**: 「따뜻하고 축축한 공기는 위로 올라가요. 올라가며 식어서 물방울이 되고 구름이 돼요.」 / 「구름 속에서 얼음 알갱이들이 부딪치며 전기가 쌓여요. 번개는 그 전기가 쏟아지는 거예요.」 / 「위와 아래 바람이 엇갈리면 올라가는 공기가 돌기 시작해요.」

**블렌더**: 평원 360° 배경(지평선·밭·길·농가·풍차·전봇대), 관측 차량 창틀과 손잡이, 풍차(부서지는 조각). **코드**: 구름(부피감 있는 덩어리를 겹쳐 속에서 빛남), 번개(과학실 번개 부품 재사용), 비 기둥, 우박, 깔때기와 흙먼지, 하늘색 변화(초록빛 도는 어둑한 하늘).

**급소**: 구름 **속에서 번쩍이는 빛**(구름이 등처럼 안에서 밝아짐). 토네이도는 가늘고 느리게 휘는 밧줄 모양이 진짜 같다. 폭풍 전 하늘의 탁한 초록. 소리: 번개 뒤 **늦게 오는 천둥**(멀수록 늦게 — 장면 1과 같은 배움), 화물 열차 같은 토네이도 소리.

### 장면 10. 자라는 결정

**약속**: 돌과 눈은 누가 깎지 않아도 스스로 모양을 만든다.

**무대**: 어두운 표본실의 유리 상자(검은 벨벳 바닥, 위에서 비추는 가는 조명) + 옆에 크기 견줄 연필과 돋보기. 결정 종류마다 상자가 바뀐다.

**손잡이**: ① 온도 다이얼 ② 물기(또는 식히는 빠르기) 다이얼 ③ 시간 빨리 감기 + 돌려 보기.

| 한 일 | 일어나는 일 |
|---|---|
| 눈 결정 — 영하 2도쯤 | 납작한 **육각 판** |
| 영하 5도쯤 | 가는 **바늘·기둥** |
| 영하 15도쯤 + 물기 많이 | 가지 여섯의 **별 모양**(나뭇가지 눈) |
| 자라는 도중 온도를 바꿈 | 가운데는 판, 끝은 가지 — **자란 역사가 모양에 남는다** |
| 같은 조건 두 번 | 닮았지만 **똑같지는 않다** |
| 소금물을 천천히 말림 | 반듯한 **정육면체** |
| 빨리 말림 | 잘고 뭉친 가루 |
| 비스무트를 녹였다 천천히 식힘 | 네모 **계단이 소용돌이치는** 탑, 겉이 무지개색 |
| 빨리 식힘 | 무늬 없는 은빛 덩어리 |
| 수정 — 아주 오래 | 육각 기둥에 뾰족한 끝 |
| 자라는 결정에 흠을 냄 | 흠을 메우며 다시 반듯해진다 |
| 거대 결정 동굴(자유) | 사람보다 큰 흰 기둥 결정들 사이에 작은 탐험가 인형 |

**의뢰**: ① 별 모양 눈을 길러라 ② 주문서와 같은 눈(가운데 판 + 끝 가지 — 도중에 온도를 바꿔야) ③ 가장 큰 무지개 계단을(식히는 빠르기 — 느릴수록 크다)

**긴장과 깊이**: 조용한 장면. 재미는 **내 것을 기르는 것** — 기른 결정은 내 표본 선반에 놓이고, 같은 것이 둘도 없다. 도감: 눈 모양 열둘(온도 × 물기 표의 칸).

**까닭**: 「아주 작은 알갱이들이 정해진 줄에 맞춰 차곡차곡 붙어요. 그래서 누가 깎지 않아도 반듯해요.」 / 「눈은 물 알갱이가 여섯 방향으로 붙어서 언제나 육각이에요.」 / 「천천히 자랄수록 크고 반듯해요.」

**블렌더**: 표본 상자·조명·다이얼·연필·돋보기, 결정의 **기본 조각 모양**(육각 판·가지 마디·정육면체·계단 한 단·수정 기둥), 무지개 겉 재질, 동굴. **코드**: 자라는 차례(규칙에 따라 조각을 붙여 감 — 온도·물기 값이 규칙을 고름), 얼음·유리의 굴절과 무지개 갈라짐, 빨리 감기.

**급소**: 얼음 결정은 **가장자리만 빛나는 투명**(속이 뿌옇면 플라스틱). 검은 바닥과 가는 조명. 비스무트의 무지개는 보는 각도에 따라 색이 흐른다. 소리: 자랄 때 아주 작은 틱틱, 유리 종 같은 맑은 울림.

### 장면 11. 점점 작아지기

**약속**: 손바닥 위의 것 속에 또 다른 세상이 있다.

**무대**: 책상 위(나비 표본, 소금 그릇, 이끼 낀 돌, 벨크로 붙은 운동화, 연필) → 열 배씩 줄어든다. 화면 구석에 **크기 자**: 연필 → 쌀알 → 머리카락 굵기 → 그 백 분의 일.

**손잡이**: ① 줄어들기·커지기 휠(쉬지 않고 이어지는 확대) ② 어디로 들어갈지 고르기 ③ 손전등.

| 들어간 곳 | 줄어들수록 보이는 것 |
|---|---|
| 나비 날개(파란 나비) | 파란 면 → **기왓장처럼 겹친 비늘** → 비늘 겉의 가는 골. 그런데 비늘 하나를 뒤집으면 **갈색** — 파랑은 물감이 아니다 |
| 소금 알갱이 | 흰 가루 → 하나하나가 **유리 주사위** |
| 이끼의 물방울 | 초록 덩어리 → 이끼 잎 숲 → 물방울 속을 뒤뚱뒤뚱 걷는 **물곰**(다리 여덟), 휙 지나가는 짚신벌레 |
| 벨크로 | 까슬한 면 → **갈고리 숲**과 고리 숲. 붙였다 떼면 갈고리가 걸렸다 풀린다 |
| 머리카락 | 한 올 → 밧줄 굵기 → 겉이 **비늘**로 덮인 기둥 |
| 연필 글씨 | 검은 선 → 종이 섬유 사이에 낀 **반짝이는 검은 조각들** |
| 모래 한 줌 | 다 같은 모래 → 알마다 색과 모양이 다른 **보석 더미**, 사이에 작은 조개 조각 |
| 꽃가루(자유) | 노란 가루 → 가시 돋친 공들 |
| 물곰을 말린다(자유) | 통처럼 오그라들어 멈춘다. 물을 주면 **다시 걷는다** |

**의뢰**: ① 물곰을 찾아 사진을 찍어라 ② 파란 나비가 왜 파란지 밝혀라(비늘을 뒤집어 봄) ③ 책상 위에서 주사위 모양을 찾아라(소금)

**긴장과 깊이**: 긴장은 없다. 재미는 **끊김 없이 줄어드는 그 느낌**과 찾기. 도감: 숨은 것 스물넷(책상 위 물건마다 세 단계).

**까닭**: 「나비의 파랑은 물감이 아니에요. 비늘에 난 아주 가는 골이 빛을 튕겨 파랗게 보이게 해요.」 / 「물곰은 다 자라도 깨알보다 작아요. 말라도, 얼어도 죽지 않고 버텨요.」

**블렌더**: 책상과 물건들, 단계마다의 모형(비늘·비늘 골·소금 결정·이끼 잎·물곰(뼈대·걸음)·짚신벌레·벨크로 갈고리·머리카락 겉·종이 섬유·모래알 열 가지). **코드**: 단계 사이를 **이어 붙이는 확대**(앞 단계가 흐려지며 다음 단계가 선명해짐), 얕은 심도, 손전등, 크기 자.

**급소**: 현미경 사진처럼 — 아주 얕은 심도, 한쪽에서 비추는 빛, 떠다니는 먼지. **확대가 끊기면 끝**이다(단계 사이 0.5초 겹침). 물곰의 느릿한 뒤뚱 걸음. 소리: 작아질수록 방 소리가 낮고 느려진다.

---

### 장면 12. 혈관 속

**약속**: 지금 이 순간 내 몸속에서 벌어지는 일.

**무대**: 아주 작은 잠수정 창(장면 3의 조종석을 줄인 것). 붉고 따뜻한 굴, 사방에 함께 떠가는 적혈구. 한 바퀴 길: 심장 → 굵은 길 → 가는 길 → 손끝의 실핏줄 → 돌아오는 길 → 심장 → 허파 → 심장.

**손잡이**: ① 흐름 타기·버티기 레버 ② 갈림길에서 길 고르기 ③ 몸 주인의 움직임 단추(쉬기 / 달리기) ④ 탐조등.

| 한 일 | 일어나는 일 |
|---|---|
| 심장 안에서 기다린다 | 문(판막)이 닫혔다가 **쿵** 열리며 왈칵 밀려 나간다 |
| 굵은 길 | 넓은 굴, 맥박마다 벽이 **불룩**거리고 빨리 흐른다 |
| 가는 길로 든다 | 점점 좁아진다 |
| 실핏줄 | 적혈구가 **한 줄로**, 몸을 접어 가며 겨우 지난다. 여기서 선홍색이 **검붉게** 바뀐다(산소를 내려놓음) |
| 돌아오는 길 | 느리다. 군데군데 한쪽으로만 열리는 문(거꾸로 못 간다) |
| 허파의 실핏줄 | 벽 너머 공기주머니가 숨 쉴 때마다 부풀고, 검붉던 것들이 **선홍색으로** 돌아온다 |
| 「달리기」를 누른다 | 쿵쿵이 빨라지고 흐름이 거세진다 |
| 벽에 난 상처를 만난다 | 작은 조각들(혈소판)이 몰려와 **그물을 치고** 구멍을 메운다 |
| 세균을 만난다 | 흰 덩어리(백혈구)가 벽을 타고 기어와 **삼킨다** |
| 흐름을 거슬러 버틴다 | 전지가 닳고 적혈구들이 창에 부딪쳐 온다 |

**의뢰**: ① 심장에서 나가 손끝까지 가라 ② 검붉은 피가 다시 붉어지는 곳을 찾아라(허파) ③ 한 바퀴를 돌아라(심장을 **두 번** 지나야 한다는 걸 알게 된다 — 몸 한 바퀴, 허파 한 바퀴)

**긴장과 깊이**: 맥박이 **장면 전체의 박자**다(소리·흐름·벽이 한 박자로). 달리기를 누르면 조종이 어려워진다. 도감: 만난 것 열(적혈구·백혈구 종류·혈소판·판막·실핏줄·공기주머니…).

**까닭**: 「피는 온몸에 산소를 배달하고 돌아와요. 심장은 쉬지 않는 펌프예요.」 / 「한 바퀴 도는 데 1분쯤 걸려요. 지금도 돌고 있어요.」

**블렌더**: 잠수정 창틀, 적혈구(가운데 오목한 원반, 접히는 모양 키), 백혈구(꿈틀 모양 키), 혈소판, 세균, 판막(여닫는 뼈대), 굴 벽 겉 그림(주름·가는 핏줄), 공기주머니. **코드**: 굴(길 따라 이어지는 대롱, 맥박에 불룩), 적혈구 수천 개 한 번에 그리기와 흐름, 색 변화(선홍 ↔ 검붉음), 뿌연 붉은 깊이감, 그물 치기.

**급소**: **살 같은 빛** — 굴 벽이 뒤에서 비친 듯 은은히 붉게 밝다(딱딱한 붉은 관이면 실패). 적혈구가 서로 밀리고 도는 것. 맥박마다 화면이 살짝 밀림. 소리: 물속에서 듣는 심장 소리 쿵-쿵, 흐르는 소리.

## 3. 만드는 차례

### 3-1. 본보기 먼저

**장면 1 불꽃놀이 공장**을 끝까지 만든다. 까닭: ① 입자와 빛 번짐이 주인공이라 화려함이 가장 확실히 나온다 ② 블렌더 몫(강변·작업대·발사통)과 코드 몫(불꽃)이 고루 들어 있어 **만드는 길 전체를 한 번에 검증**한다 ③ 저학년도 바로 한다 ④ 여기서 만든 입자·빛 번짐·야경 굽기·소리 지연을 뒤 장면들이 쓴다.

**준호가 불꽃놀이를 직접 보고 "이 그림이면 된다"고 하기 전에는 다른 장면의 그림을 시작하지 않는다.**

### 3-2. 그다음

| 차례 | 장면 | 까닭 |
|---|---|---|
| 1 | 불꽃놀이 공장 | 본보기 |
| 2 | 블랙홀 | 셰이더 하나가 주인공. 생물·지형이 없어 빨리 선다. 고학년용 한 방 |
| 3 | 자라는 결정 | 조용하지만 실사가 가장 잘 나온다(유리·얼음) |
| 4 | 깊은 바다 | 첫 생물. 어둠이 받쳐 준다. 혼자 오래 하는 장면 |
| 5 | 화산 속 | 지형 굽기 + 용암 |
| 6 | 폭풍 만들기 | 구름 덩어리가 어렵다 |
| 7 | 토성 고리 속 → 8 달 만들기 → 9 태양 가까이 → 10 오로라 | 우주 부품을 이어 쓴다 |
| 11 | 혈관 속 → 12 점점 작아지기 | 모형이 가장 많다. 맨 끝 |

### 3-3. 장면 하나의 묶음 여섯

| 묶음 | 하는 일 | 끝난 기준 |
|---|---|---|
| ㄱ 손잡이 판 | 그림 없이 회색 도형으로 손잡이와 결과표가 돈다(터치·마우스) | 「이렇게 하면 → 이렇게 된다」 표의 모든 줄이 글자로라도 나온다. node 시험 통과 |
| ㄴ 5초 장관 | 손대지 않은 첫 화면만 실사 수준으로 | 화면을 찍어 블렌더 기준 그림과 나란히 본다 |
| ㄷ 물건 | 블렌더로 조종석·손잡이·모형 | 기준 그림 한 장씩 |
| ㄹ 효과 | 결과표의 모든 줄에 그림과 소리 | 하 등급 초당 30장 |
| ㅁ 의뢰와 까닭 | 의뢰 셋·까닭·자유·도감 | 처음부터 끝까지 한 판 |
| ㅂ ✋ 준호 눈 확인 | 준호가 크롬북으로 직접 | 답: 된다 / 무엇이 걸린다 |

본보기(불꽃놀이)만 **ㄴ 뒤에도 ✋ 한 번 더** 둔다 — 첫 화면 그림 수준을 가장 먼저 확인한다.

### 3-4. 코드 자리

```
k-edu/wonder/
  index.html              열두 장면이 걸린 어두운 전시 복도(장면마다 움직이는 창 하나)
  core/                   stage(화질 등급·카메라 컷) · input(터치·마우스·케이모션 손) · flow(의뢰·까닭·도감)
                          fx/ particles · glow · clouds · bolt   audio
  scene/<이름>/           scene.json(결과표·의뢰·문구) · <이름>.js · assets/
  tests/
handoff/wonder/blender/   common.py · <이름>.py · renders/
```

- 과학실(`kmotion/lab/core`)과 겹치는 부품(화질 등급, 번개, 안개, 의뢰 흐름)은 **먼저 선 쪽의 것을 그대로 베껴 와 쓰고**, 둘 다 선 뒤에 공용으로 올릴지 정한다. 지금 공용부터 만들지 않는다.
- Three.js 는 `/labs/vendor/three185/` 그대로.
- 화면 글자에 영어 코드를 쓰지 않는다. 문구는 전부 `scene.json`.
