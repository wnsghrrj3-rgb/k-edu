짝 문서: `volcano_design_v1.md`(무엇을 만드나). 이 문서는 **어떻게, 어떤 차례로** 만드나.
본보기 코드: `wonder/fireworks/`(입자·강물 반사·화면 찍기), `wonder/blackhole/`(조종석 한 장 굽기·계기 화면 붙이기·`?shot=1`).

---

## 0. 먼저 알 것 — 지난번에 왜 틀어졌나

2026-11-23 아침, 열한 장면이 "그림 없이 계산부터"로 한꺼번에 만들어져 회색 도형 화면이 복도에 걸렸고, 준호가 「최악, 안 만드느니만 못하다」고 했다. 그래서:

1. **회색 판을 만들지 않는다.** 묶음 1의 끝은 "보여 줄 수 있는 그림"이다.
2. **한 번에 묶음 하나.** 끝나면 멈추고 준호에게 주소를 준다. 답을 듣기 전에 다음 묶음을 시작하지 않는다.
3. **복도 카드(`wonder/index.html`)는 준호가 "된다"고 한 뒤에만 연다.** 그 전에는 주소로만 들어간다.
4. **화면을 찍어 눈으로 보고 고친다.** 찍어 보지 않은 그림은 끝난 것이 아니다. 한 번 찍고 끝내지 말고, 4장의 점검표가 다 맞을 때까지 되풀이한다.
5. 모델은 **페이블**로. 이 장면은 그림과 계산이 붙어 있어 나눠 맡기지 않는다(묶음 5 채우기만 오푸스로 해도 된다).

## 2. 묶음 1 — 첫 화면 (여기까지 하고 멈춘다)

**만들 것**: 해 질 녘 바다 한가운데에서 화산섬이 **스스로 분출하며 자라는** 장면. 들어오자마자 돌아가고 있어야 한다. 손잡이는 끈적임과 기체 둘(임시 단추여도 된다). 시간이 저절로 빨리 감겨서 1~2분이면 바다 밑 둔덕이 산이 된다.

### 2-1. 계산 (`terrain.js`, 이번에는 규칙 둘만)

- 격자 `N×N`(상 192, 하 128), `Float32Array` 로 `base·rock·tephra·melt·heat·age`, `Uint8Array` 로 `kind`.
- `step(dt)`: ① 분출구 칸에 `melt`·`heat` 넣기 ② 흐르기: 칸마다 여덟 이웃 중 낮은 쪽으로, 양 = (높이 차) ÷ 끈적임, 두께 × 기울기가 문턱 아래면 안 움직임 ③ 식기: `heat` 감소(물 밑이면 훨씬 빨리), 0 이 되면 `melt → rock`, `age = 0` ④ 부스러기: 폭발 세기에 따라 분출구 둘레 고리에 `tephra` 더하기, 30도 넘으면 이웃으로 미끄러짐 ⑤ `age += dt`.
- 한 걸음에 옮기는 양은 가진 양의 일부로 묶어서 출렁임이 없게 한다. **뿜은 부피 = 쌓인 부피**를 시험한다.
- 설계 2-6 의 시험 문장 가운데 이번 규칙에 해당하는 것(방패·돔·원뿔·번갈아·부피) 다섯을 `node` 시험으로.
- 숫자(끈적임에 따른 흐름 빠르기, 식는 빠르기)는 **그림을 보면서** 맞춘다. 방패와 돔이 눈으로 확 달라야 한다.

### 2-2. 그림 (`scene.js`)

| 것 | 방법 |
|---|---|
| 땅 | 격자 값을 `DataTexture`(float) 두 장에 담는다(높이·녹은 두께·뜨거움 / 종류·나이). `PlaneGeometry(N−1 칸)` 을 정점 셰이더에서 높이만큼 올린다. 법선은 조각 셰이더에서 높이 그림의 이웃 차로. 매 계산 걸음 뒤 `needsUpdate`. |
| 땅 겉 | 종류와 나이로 색을 고른다: 갓 굳은 용암 = 검고 반들(거칠기 낮음), 오래된 용암 = 잿빛, 재 = 누런 잿빛(매끈), 나이가 차면 낮은 곳부터 이끼 → 풀. 위에 잔 무늬(fbm)를 기울기 방향으로 늘여 흐른 자국처럼. 바닷가 한 칸은 젖은 검정. |
| 용암 | `melt > 0` 인 곳. **통째로 빛나게 하지 않는다.** 껍질 무늬(잔 무늬를 문턱으로 자름)를 만들어 껍질은 검게, 틈만 뜨거움에 따라 흰 노랑 → 주황 → 검붉게. 무늬는 낮은 쪽으로 천천히 흐르게. 뜨거운 곳 위에 아지랑이는 생략해도 된다. 빛 번짐(블룸)을 건다. |
| 바다 | 불꽃놀이의 강물 방식(지난 프레임을 위아래로 번지게 해 뒤집어 비춤) + 땅 높이 그림을 읽어 **얕은 곳은 밝은 청록, 물가에 흰 거품 띠**. 용암이 닿은 칸 둘레는 탁한 연두. |
| 김 | 용암이 바다 칸에 들어가는 자리에서 흰 입자가 솟아 바람에 눕는다. |
| 분출 | 불 분수 = 불꽃놀이의 별 입자를 그대로(중력·꼬리). 재 기둥 = 크고 느린 연기 입자, 아래는 용암 빛에 붉게 물들고 위는 저녁 햇빛에 가장자리가 빛남. 큰 폭발 때 기둥 속 번개(블랙홀·과학실의 번개 부품이 없으면 꺾은선 두세 프레임). |
| 하늘 | 해가 수평선 가까이. 주황 → 남색. 엷은 구름 띠. 별 몇 개. |
| 크기 견줌 | 블렌더로 만든 고깃배 한 척과 등대 하나(GLB). 섬이 물 위로 올라온 뒤 물가에 등대를 세운다. 배는 멀리 지나간다. |
| 눈 | 비스듬히 내려다보는 한자리. 가로로 끌면 섬 둘레를 천천히 돈다. 걸어 다니지 않는다. |

화질 셋(상·중·하)을 스스로 내리게(불꽃놀이 `tune` 방식). `?q=` 로 고정, `?shot=1` 로 시간을 손으로 감아 찍기.

### 2-3. 저절로 돌아가는 쇼

들어오면: 바다가 부글거림 → 검은 섬이 얼굴을 내밂 → 묽은 용암이 흘러 섬이 넓어짐 → 불 분수와 부스러기로 원뿔이 섬 → 한 번 크게 폭발. 그 사이 시간이 감기며 오래된 쪽에 풀이 돋는다. 다 자라면 가라앉히고 처음부터(또는 그대로 두고 손잡이를 열어 줌). 손을 대면 쇼를 멈추고 손잡이를 따른다.

### 2-4. 블렌더 몫 (이번 묶음)

- `volcano_props.py`: 고깃배, 등대(모서리 깎기, 흠, 실제 치수) → GLB.
- `volcano_sky.py`: 해 질 녘 하늘 360° 그림(없으면 셰이더로 만들고 넘어간다).
- 조종판(관측소 한 장 굽기)은 묶음 2에서. 이번에는 화면 아래 임시 단추 둘.

### 2-5. 끝난 기준

1. `node wonder/tests/test_volcano_terrain.mjs` 통과.
2. 4장의 점검표가 화면 사진으로 다 확인됨. 사진을 `wonder/volcano/_shots/` 에 남긴다(첫 화면, 방패로 기른 섬, 돔으로 기른 섬, 대폭발 순간, 용암이 바다에 닿는 순간).
3. 실제 그래픽 카드에서 초당 30장(하 등급 포함).
4. `_WONDER_STATUS.md` 에 한 일과 못 한 것을 적고 커밋·푸시.
5. **복도 카드는 열지 않는다.** 준호에게 한 줄: 주소 `keduclass.com/wonder/volcano/` 와 「이 그림이면 되는지, 산이 자라는 것이 보이는지」.

## 4. 그림 점검표 (찍은 사진을 이것과 견준다)

- [ ] 용암이 **통째로 주황이 아니다.** 검은 껍질 사이로 틈만 빛난다.
- [ ] 묽게 기른 섬과 끈적하게 기른 섬이 **옆모습만 봐도 다르다.**
- [ ] 새로 굳은 땅(검정)과 오래된 땅(잿빛·풀색)이 색으로 구별된다.
- [ ] 재 기둥이 느리다. 꼭대기가 옆으로 퍼진다.
- [ ] 바다가 평평한 색 판이 아니다. 물가 거품, 얕은 곳의 청록, 수면에 비친 용암 빛과 저녁 하늘이 있다.
- [ ] 용암이 바다에 닿는 자리에 김이 선다.
- [ ] 등대나 배가 보여서 섬이 얼마나 큰지 안다.
- [ ] 땅의 격자 계단이 눈에 띄지 않는다(법선·잔 무늬로 가린다).
- [ ] 화면에 막대·점수·영어 코드가 없다.
- [ ] 불꽃놀이·블랙홀 옆에 놓아도 처지지 않는다. 처지면 끝난 것이 아니다.
