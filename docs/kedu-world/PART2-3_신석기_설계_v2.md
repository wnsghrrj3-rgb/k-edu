## §0 구조 — PART I 과 같은 뼈대, 시간이 「계절」로 흐른다

```
 회상 카드(PART I 정리) → INTERLUDE(같은 강, 시간 가속) → 프롤로그(눈을 뜬다)
 → ACT 15~29 (미션 41개, 하나씩) → ACT 30 이름 「신석기 시대」 + 정리(되짚기 5 + 열린 1)
 → ACT 31 발굴(확인 5) → ACT 32 실제 유적(추론 3) → FINALE(탐험일지 두 열) → EPILOGUE(낯선 사람) → 문(PART IV)
```
- **깃발 이름 규칙**: `<동사>:<대상>` 소문자, 시대 이름 없음. ACT 단계 깃발은 `act15`…`act32`(사건이 세운다).
- **계절**: 세계 시계 `season` = 봄→여름→가을→겨울, 사건 `{season:'next'}` 로만 넘어간다(실시간 아님). 밭·강·하늘·소리(벌레·바람)가 계절을 따른다.
- **능력 누적**: PART I 의 targets/recipes(열매·뿌리·흔적·뗀석기·불·가지·거처)를 `items.json` 에 그대로 두고, 새 것을 **추가**한다. 뺀 것 없음.
- **정본 「절대로 해서는 안 되는 것」**: 시대 이름·연도 미리 말하기 ✗, 왕·명령 ✗, 마법 같은 성공 ✗, 승리 팡파르 ✗, 도구 설명을 필요 앞에 ✗.

## §3 새 코어 5 — 데이터 형식과 규칙(시대 이름 0)

### 3.1 밭 `core/plot.js` — `world.plots`
```json
"plots": [{ "id": "p_me", "at": [6,4], "cells": [3,3], "owner": "player", "crop": "grain",
            "stages": ["bare","seed","sprout","grown","ripe","withered"], "waterDays": 2, "weedChance": 0.35 }]
```
- 칸 상태: `bare → (심기) seed → (계절 tick +물) sprout → (tick +물) grown → (tick) ripe → (수확) bare` · 물 안 주고 tick → `withered`(회복 불가, 다시 심기) · 잡초 확률로 `weed` 표시 → 뽑기 안 하면 성장 정지.
- 학생 행동(대상 `plot_cell`): 심기(씨앗 1) · 물주기(물 담을 것 필요 — 가죽 주머니 → 뒤엔 토기, 토기는 3칸 한 번에) · 잡초 뽑기 · 수확(곡물 2 + 씨앗 1).
- 결과 규칙: 첫 계절 9칸 중 성공 3~5칸이 나오도록(정본 「일부는 실패」) — 잡초 35%·물 잊음.
- 한이 밭(`p_hani`, 5×5)은 자동 성장(보는 용).
- 시험: tick 3회에 물 준 칸만 ripe, 안 준 칸 withered, 수확량 계산.
