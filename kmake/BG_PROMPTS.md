# 케이메이크 배경 제작 — Claude Design 프롬프트 모음

> 사용법: 아래 프롬프트를 Claude Design에 붙여넣기 → SVG 결과를 받아 → 맨 아래 "변환·등록" 절차대로 `backgrounds.js`에 넣는다.
> 한 프롬프트당 4~6종씩 변형(색만 다른 버전)을 요청하면 효율이 좋다.

---

## 공통 기술 제약 (모든 프롬프트 끝에 반드시 붙일 것)

```
[기술 제약 — 반드시 지켜줘]
- 정확히 viewBox="0 0 1200 800" 인 SVG 1개로 출력
- fabric.js 5.x 캔버스에 임포트되므로: <filter>, <mask>, <pattern>, <text>, <image>, CSS class, <style> 태그 절대 금지
- 허용 요소: rect, circle, ellipse, path, polygon, line, g + linearGradient/radialGradient (defs 안에)
- 모든 스타일은 inline 속성(fill, stroke, opacity 등)으로만
- 위에 글자가 올라가는 "배경"이므로 중앙부는 비우거나 차분하게, 장식은 가장자리·모서리 위주
- 요소 수 200개 이하 (파일 크기 절약)
```

---

## 카테고리 1 — 파스텔·그라데이션 (cat: `pastel`)

```
초등학교 수업자료·카드 뒤에 깔 부드러운 파스텔 그라데이션 배경 SVG를 6종 만들어줘.
각각 다른 색 조합: ①하늘색→연보라 ②복숭아→크림 ③민트→연하늘 ④연분홍→라벤더 ⑤레몬→살구 ⑥연두→하늘
- 대각선 또는 상하 linearGradient 1~2개만 사용
- 모서리에 큰 반투명 원(blob) 1~2개 정도로 깊이감만 살짝
- 유치하지 않게, 채도 낮고 우아하게
```

## 카테고리 2 — 도형 패턴 (cat: `pattern`)

```
초등 교실 디자인 도구용 "은은한 도형 패턴" 배경 SVG를 6종 만들어줘.
①물방울 도트 ②사선 줄무늬 ③모눈(그리드) ④구름 뭉게뭉게 ⑤별 흩뿌림 ⑥삼각형 콘페티
- 바탕은 아주 연한 단색, 패턴 요소는 opacity 0.15~0.35로 흐리게 (글자가 위에 올라감)
- 패턴은 <pattern> 태그 금지 — rect/circle/path를 직접 반복 배치 (g로 묶어서)
- 반복 배치 요소는 100~150개 이내로
```

## 카테고리 3 — 계절·자연 (cat: `season`)

```
초등학교용 계절 테마 배경 SVG 4종: ①봄(벚꽃잎 흩날림, 연분홍) ②여름(파도+해변, 청량한 블루)
③가을(단풍잎·은행잎, 따뜻한 주황) ④겨울(눈송이·눈언덕, 차가운 블루화이트)
- 장식 요소(꽃잎·잎·눈송이)는 가장자리와 위쪽 모서리에 몰고 중앙 60%는 비울 것
- 잎·꽃잎은 단순한 path 실루엣으로, 디테일 과하지 않게
- 하단에 완만한 언덕/파도 실루엣 1~2겹 정도는 좋음
```

## 카테고리 4 — 교실·칠판 (cat: `class`)

```
초등 교실 느낌 배경 SVG 4종:
①초록 칠판(질감은 미묘한 명도 변화 사각형 몇 개로, 테두리는 나무색 프레임) — 필기 글씨가 올라갈 예정
②검은 칠판 + 모서리에 분필 느낌 흰 별·동그라미 낙서 약간
③코르크 게시판(갈색 바탕 + 모서리 압정 동그라미 4개)
④줄공책(흰 바탕 + 연한 하늘색 가로줄 + 왼쪽 빨간 세로 여백선)
- filter/texture 이미지 금지, 전부 단순 도형으로 표현
```

## 카테고리 5 — 축하·이벤트 (cat: `party`)

```
학급 행사용 축하 배경 SVG 5종: ①생일(콘페티+풍선 실루엣, 밝은 파스텔) ②칭찬·시상(금색 별+리본, 네이비 바탕)
③크리스마스(눈송이+트리 실루엣, 딥그린·레드) ④할로윈(호박·박쥐 실루엣, 보라·주황) ⑤운동회(만국기 가랜드, 하늘색)
- 장식은 상단 모서리와 하단 가장자리에 집중, 중앙은 텍스트 공간으로 비울 것
- 풍선·깃발 등은 flat한 단색 실루엣 + 살짝 다른 명도 2~3색
```

## 카테고리 6 — 프레임·테두리 (cat: `frame`)

```
인쇄해서 쓰는 안내문·상장용 "테두리 프레임" 배경 SVG 5종:
①골드 이중선 클래식 프레임(상장용, 모서리 장식 포함) ②알록달록 크레용 손그림 느낌 테두리
③잎사귀 덩굴 프레임(연그린) ④무지개 라운드 프레임 ⑤점선 티켓 프레임(모서리 반원 펀칭)
- 바탕은 흰색 또는 아주 연한 크림색
- 프레임 두께는 가장자리에서 30~70px 이내, 안쪽은 완전히 비울 것
```

## 변환·등록 절차

1. Claude Design 결과에서 `<svg ...>` 와 `</svg>` 바깥 태그를 제거하고 **안쪽 내용만** 복사
   (viewBox가 1200×800이 아니면 다시 요청)
2. `backgrounds.js`에 아래 형식으로 추가:

```js
window.BG_CATS = [
  ["pastel", "파스텔"],
  ["pattern", "패턴"],
  ["season", "계절"],
  ["class", "교실·칠판"],
  ["party", "축하·행사"],
  ["frame", "프레임"],
];
window.BACKGROUNDS = [
  { n: "하늘색 그라데이션", c: "pastel", s: `<defs>...</defs><rect .../>` },
  // ...
];
```

3. 로컬에서 배경 패널 열어 썸네일·적용 확인 → 커밋·푸시

## 검수 체크리스트
- [ ] 배경 패널 썸네일에서 깨지지 않는가 (gradient id 충돌 주의 — 배경마다 id를 다르게: `bg1grad`, `bg2grad`...)
- [ ] 캔버스에 적용 후 텍스트 가독성이 확보되는가 (중앙부가 차분한가)
- [ ] PNG 내보내기에서 색이 그대로 나오는가
