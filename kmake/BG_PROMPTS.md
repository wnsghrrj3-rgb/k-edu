# 케이메이크 배경 30종 — Claude Design 프롬프트북

사용법: **맨 아래 [공통 제약]을 복사해서 각 프롬프트 끝에 붙인 뒤** Claude Design에 넣는다.
결과 SVG는 변환 없이 통째로 베프에게 전달 → backgrounds.js 등록·검수는 베프가 처리.

## A. 파스텔 그라데이션 (5종) — 만능 기본 배경

**A1. 하늘 파스텔**
```
연한 하늘색(#D6E9FF)에서 연보라(#E8DFFB)로 흐르는 대각선 그라데이션 배경 SVG.
오른쪽 위 모서리에 흰색 반투명 큰 원 1개, 왼쪽 아래에 연보라 반투명 원 1개로 깊이감만 살짝.
채도 낮고 우아하게, 유치하지 않게.
```

**A2. 복숭아 크림**
```
복숭아색(#FFE3D3)에서 크림색(#FFF8EC)으로 흐르는 상하 그라데이션 배경 SVG.
하단에 살구색 반투명 물결 곡선 실루엣 1겹. 따뜻하고 부드러운 느낌.
```

**A3. 민트 프레시**
```
민트(#D9F4EC)에서 연하늘(#E3F1FF)로 흐르는 대각선 그라데이션 배경 SVG.
왼쪽 위 모서리에 흰색 반투명 원 2개가 겹친 장식. 청량하고 깨끗한 느낌.
```

**A4. 핑크 라벤더**
```
연분홍(#FFE4EF)에서 라벤더(#E9E2FA)로 흐르는 그라데이션 배경 SVG.
네 모서리에 아주 연한 흰색 반짝이(4각 별 path) 5~6개를 작게 흩뿌림. 사랑스럽지만 차분하게.
```

**A5. 레몬 선샤인**
```
레몬(#FFF6CC)에서 살구(#FFE8D1)로 흐르는 방사형(radialGradient, 좌상단 중심) 배경 SVG.
오른쪽 아래에 연주황 반투명 원 1개. 아침 햇살처럼 밝고 따뜻하게.
```

## B. 은은한 패턴 (5종) — 글자가 잘 보이는 배경

**B1. 물방울 도트**
```
아주 연한 크림 바탕(#FDFBF5)에 연하늘 동그라미 도트(opacity 0.25)를 격자로 반복 배치한 배경 SVG.
도트 지름 14px, 간격 80px, <pattern> 태그 금지하고 circle을 직접 반복 배치(g로 묶기), 150개 이내.
```

**B2. 사선 줄무늬**
```
흰 바탕에 연한 민트색 굵은 사선 줄무늬(45도, opacity 0.18)가 일정 간격으로 반복되는 배경 SVG.
줄 두께 28px, 간격 70px. rect를 회전 배치하거나 path로 직접 그리기.
```

**B3. 모눈 그리드**
```
흰 바탕에 아주 연한 회청색(#DCE4F0) 가는 선으로 된 모눈종이 그리드 배경 SVG.
칸 크기 50px, 선 두께 1px. line 요소를 직접 반복 배치. 수학 학습지 느낌.
```

**B4. 별 흩뿌림**
```
아주 연한 미색 바탕에 노랑·하늘·분홍 작은 별(5각 path, opacity 0.3)을 무작위처럼 흩뿌린 배경 SVG.
별 크기 10~20px로 다양하게, 60~80개, 중앙 50% 영역은 밀도를 절반으로 낮출 것.
```

**B5. 구름 뭉게뭉게**
```
연하늘 바탕(#EAF4FF)에 흰색 뭉게구름 실루엣(둥근 circle 3~4개 합친 path)을 상단과 하단 가장자리에 배치한 배경 SVG.
구름 6~8개, opacity 0.7~0.9, 중앙은 비울 것.
```

## C. 계절·자연 (6종) — 계기교육·계절 행사

**C1. 봄 벚꽃**
```
연분홍 그라데이션 바탕에 벚꽃잎(둥근 물방울형 path, 분홍 2~3톤)이 위에서 흩날리는 배경 SVG.
꽃잎은 상단과 좌우 가장자리에 25~35개, 회전 다양하게, 중앙 60%는 비울 것.
```

**C2. 여름 바다**
```
청량한 하늘색 바탕, 하단 30%에 파도 실루엣 2겹(진한 블루·연한 블루), 오른쪽 위에 흰 태양 원과 광선.
좌측 하단에 작은 비치볼(3색 원) 1개. 시원하고 깨끗하게.
```

**C3. 가을 단풍**
```
따뜻한 미색 바탕에 단풍잎(빨강·주황)과 은행잎(노랑) 실루엣 path가 가장자리를 따라 흩어진 배경 SVG.
잎 20~30개, 단순한 실루엣으로, 하단에 완만한 갈색 언덕 실루엣 1겹.
```

**C4. 겨울 눈**
```
차가운 블루화이트 그라데이션 바탕, 흰 눈송이(6각 대칭 path) 크고 작게 15~20개, 하단에 흰 눈언덕 실루엣 2겹.
눈송이는 상단 위주, 중앙은 비울 것.
```

**C5. 밤하늘**
```
딥네이비(#1B2A4A)에서 미드나잇블루로 흐르는 그라데이션 바탕, 흰·노랑 별 점 40~50개,
오른쪽 위에 노란 초승달, 하단에 진한 남색 산 능선 실루엣 1겹. 차분하고 신비롭게.
```

**C6. 초록 숲**
```
연두 그라데이션 바탕, 좌우 가장자리에 진초록·연두 나뭇잎 실루엣이 안쪽으로 살짝 들어온 프레임형 배경 SVG.
잎은 단순한 타원·물방울 path 조합, 중앙은 완전히 비울 것.
```

## D. 교실·학습 (5종) — 학습지·발표자료 단골

**D1. 초록 칠판**
```
진초록(#2F5E4E) 칠판 배경 SVG. 가장자리에 나무색(#B98A5A) 프레임(두께 36px),
칠판면은 명도가 미묘하게 다른 큰 사각형 2~3개 겹쳐 질감 표현. 위에 분필 글씨가 올라갈 예정.
```

**D2. 검정 칠판 낙서**
```
짙은 차콜(#2B2D31) 칠판 배경 SVG. 네 모서리에 흰 분필 느낌 낙서(별·동그라미·물결선, stroke만, opacity 0.6) 약간.
중앙은 비울 것.
```

**D3. 코르크 게시판**
```
코르크 갈색(#C89F6E) 바탕에 더 진한 갈색 작은 점(opacity 0.25) 80개로 코르크 질감,
네 모서리에 빨강·파랑 압정(원+작은 원 하이라이트) 4개. 게시물 안내문용.
```

**D4. 줄공책**
```
흰 바탕에 연하늘 가로줄(간격 56px, 두께 2px) + 왼쪽에서 90px 위치에 빨간 세로 여백선 1개.
상단 140px은 줄 없이 비울 것(제목 영역). 받아쓰기·글쓰기 학습지용.
```

**D5. 모눈 노트**
```
아주 연한 미색 바탕에 연회색 모눈(40px 칸) + 상단에 연노랑 가로 띠(높이 100px, 제목 영역).
수학 풀이·그래프 학습지용.
```

## E. 축하·행사 (5종) — 학급 이벤트

**E1. 생일 축하**
```
밝은 파스텔 크림 바탕, 상단에서 색색 콘페티(작은 사각형·원·삼각형, 6색)가 떨어지는 배경 SVG.
좌우 하단 모서리에 파스텔 풍선 실루엣 2~3개씩. 중앙은 비울 것.

**E2. 칭찬·시상**
```
딥네이비 바탕에 금색(#D4AF37) 별과 반짝이가 상단 모서리에서 흩어지고,
하단 중앙에 금색 월계수 잎 가지 한 쌍이 마주보는 배경 SVG. 상장·시상식용, 고급스럽게.

**E3. 크리스마스**
```
딥그린 바탕, 흰 눈송이 15개, 하단에 진초록 트리 실루엣 3~4그루와 흰 눈바닥,

**E4. 할로윈**
```
보라(#3D2B56) 그라데이션 바탕, 주황 호박 실루엣 2개(하단 모서리), 검정 박쥐 실루엣 4~5마리(상단),

```

**E5. 운동회**
```
밝은 하늘색 바탕, 상단에 만국기 가랜드 2줄(삼각 깃발, 빨강·노랑·파랑·초록 반복),
하단에 연두 잔디 실루엣. 활기차게.

## F. 프레임·테두리 (4종) — 인쇄물·상장

**F1. 골드 클래식 상장**
```
흰 바탕에 금색(#C9A227) 이중선 직사각 프레임(바깥선 굵게 6px, 안쪽선 가늘게 2px, 가장자리에서 40px),
네 모서리에 금색 모서리 장식(작은 곡선 플러리시). 상장·임명장용 클래식.
```

**F2. 크레용 손그림**
```
흰 바탕에 알록달록 크레용으로 그린 듯한 삐뚤빼뚤 테두리(빨·주·노·초·파 짧은 선들이 이어진 프레임).
stroke-linecap="round", 두께 10~14px, 가장자리에서 50px. 어린이 작품 게시용.
```

**F3. 잎사귀 덩굴**
```
아주 연한 크림 바탕, 연그린 덩굴 줄기와 잎이 네 변을 따라 도는 프레임 배경 SVG.
모서리 4곳은 잎을 풍성하게, 변 중앙은 가늘게. 안쪽은 완전히 비울 것. 환경·식물 주제용.
```

**F4. 점선 티켓**
```
연노랑 바탕에 흰색 티켓 모양(둥근 모서리 큰 사각형, 가장자리에서 45px) + 그 테두리를 따라 회색 점선,
티켓 좌우 변 중앙에 반원 펀칭(바탕색 원). 쿠폰·이용권·초대권용.
```

## [공통 제약] — 모든 프롬프트 끝에 복사해서 붙이기

```
[기술 제약 — 반드시 지켜줘]
- 정확히 viewBox="0 0 1200 800" 인 SVG 1개로 출력
- fabric.js 5.x 캔버스에 임포트됨: <filter>, <mask>, <pattern>, <text>, <image>, CSS class, <style> 태그 절대 금지
- 허용 요소: rect, circle, ellipse, path, polygon, line, g + linearGradient/radialGradient(defs 안)
- 모든 스타일은 inline 속성(fill, stroke, opacity 등)으로만
- 위에 글자가 올라가는 "배경"이므로 중앙부는 차분하게, 장식은 가장자리·모서리 위주
- 요소 수 200개 이하
- gradient id는 배경마다 고유하게 (예: bgA1grad)
```
